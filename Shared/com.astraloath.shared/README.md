# AstralOath.Shared

反击动作通过已有可空 `StatusKind` 区分反击状态与被动、闪避或神器来源。来源取自本次触发的权威分支，客户端可据此选择效果词图标。[反击与回放约定](../../docs/delivery/2026-11-22-battle-action-recovery.md)

`Runtime/Battle` 是客户端模拟战与服务端共用的纯 C# 战斗内核。服务端的 `BattleMatch.Submit` 校验回合、选定目标和魂力，再由 `BattleSkillResolver` 按正式配表生成事件。战斗种子控制命中、抗性、协攻及随机技能分支。角色表现消费已选定的表现图和事件。

规则版本 17 支持 70 名英雄。按结算时的防御状态和在场亚乌利斯计算防御，受击者的烧伤、出血也读取穿透抗性，自身防御加伤读取施法者的有效防御。进战时保留怪物品阶。冻伤阻止受到的伤害降低及分配，破裂在每次攻击的普通伤害之后逐名结算。璐璐卡「复仇的波动」叠加的攻击加成保存在角色状态快照中，同场技能与重连续接读取同一状态。 [效果复核](../../docs/delivery/2026-11-20-roster61-70-effect-audit.md)

持有英雄试战和英雄面板共用 `EquipmentStatCalculator`。六个部位的主副词条使用整数，`attackPct`、`healthPct`、`defensePct` 及概率属性以万分比计。装备先将同一百分比词条相加，乘成长、觉醒后的对应裸属性，向下取整，再加入固定数值。速度四件提高裸速度 25%，暴击每两件提高 1200 万分点。神器的固定攻击与生命在装备结算后加入。裸速 100 搭配速度四件与速度 +40，结果为 165。这里的取整顺序为项目首期规则。战斗内的效果上限仍在各自的结算步骤判定。

持有试战在玩家库存事务中批量读取所选英雄实例的六槽主副词条。入场即固定双方实际面板，房间续接沿用场内快照。持有试战的内容哈希由战斗目录、神器目录、训练装备目录以及公式版本 `equipment.stats.v1` 共同构成。统一面板模拟战沿用模板成长。[实施方案与适用范围](../../docs/plans/2026-11-21-equipment-system.md)

配置入口及测试见 [Config](../../Config/README.md)、[战斗执行](../../docs/development/battle-execution.md) 与[第 61–70 位角色机制](../../docs/delivery/2026-11-20-roster61-70-skills.md)。

## 单件装备分数

`EquipmentScoreCalculator.Calculate` 接受单件装备，或一条主属性和至多四条副属性。每条数值按主、副分别加权，合计后向下取整。使用装备当前的词条数值即可，穿戴者、已激活的套装、装备等级和强化等级均无需另加分。内部整数计算保留十万分之一分；协议中 1300 万分点等于界面 13%。

下列系数以界面显示的一个数值单位或一个百分点为单位，顺序为主属性／副属性。

- 固定攻击为 0.0498／0.0972，固定生命为 0.0093／0.02，固定防御为 0.0844／0.135。
- 速度为 0.588／2，暴击率为 0.435／1.6，暴击伤害为 0.375／1.14。
- 百分比攻击、防御、生命、效果命中和效果抗性均为 0.4／1。
