# 召唤服务

当前可用卡池为誓约召唤和伊赛丽亚／星辰之歌。服务器生成概率明细和每抽结果，客户端展示已提交回执。英雄资格取自经筛选的现有战斗目录，神器资格取自神器目录的可召唤标记。

## 卡池口径

配置文件是 summon-banners.json。国服实录缺少普通誓约完整概率页，本项目使用可追溯的窄池配置。基础英雄三星 45.35%、四星 5%、五星 1.25%，另有五星月光 0.15%。三星和四星月光候选未接入，同星级的权重合并到基础英雄。神器三星 40%、四星 6.5%、五星 1.75%。伊赛丽亚池里，五星英雄 1%、四星英雄 4.5%、三星英雄 41.25%，当期五星神器 1.05%、其他五星神器合计 0.7%、四星神器 6.5%、三星神器 45%。

相同分组的物品均匀分配，整数权重显示到十万分之一百分点。愿望单只调整常驻基础五星英雄与五星神器的可抽名单，各选 7 项。改动愿望单后常驻版本标识随之变化。UP 池只保底伊赛丽亚，120 次未取得后下一抽保证，抽到她重置。每次十连顺序处理全部十个位置。

本项目每区服在北京时间 03:00 重置免费誓约一次。书签单抽 5 张、十连 50 张。常驻允许选择史诗书签或誓约书签，UP 使用誓约书签。开发访客首次访问一次性取得 60 张誓约书签，正式账号初始书签为零。

## API

请求使用区服 Bearer 会话。读取和修改均按当前玩家与区服隔离。

- GET /api/summon 读取余额、免费刷新、愿望单与概率。
- PUT /api/summon/wishlist 提交 heroes 和 artifacts 两组 ID。
- POST /api/summon/draw 提交 bannerId、revision、count、payment、requestId。支付类型为 free、bookmarks 或 epic_bookmarks。请求 ID 为非空的 32 位 GUID。网络重试必须复用原请求 ID 和参数。
- GET /api/summon/draw/{requestId} 或 GET /api/summon/draw/latest 读已完成回执。回执余额是提交时余额。客户端正常刷新使用当前状态接口。
- GET /api/summon/storage 读保管箱。POST /api/summon/storage/claim 根据 instanceIds 原子领取不超过 10 个实例。

抽取、收费、回执、保底、物品发放和审计同事务完成。抽卡前按整批最坏情况核验英雄、神器和保管箱组合容量。背包存满后剩余实例进入保管箱，领取时保留原实例 ID。保管箱最多 400 件。

### 活动时间与顶栏道具

本机伊赛丽亚测试池在北京时间 2026-12-03 03:00 结束，由 summon-banners.json 的 endUtc 控制。保留原有起点与保底记录。状态返回 serverTimeUtc 和当前有效池的 endUtc，服务端在截止时立即拒绝该池的新抽取，已有回执可继续读取。

迁移 013 为已有区服钱包增加道具余额表。GET /api/summon 额外返回 goldTransmitStones、galaxyBookmarks、mysticMedals、skystones 四个整数。没有发放记录的玩家为零；誓约书签、史诗书签、免费次数维持原有来源。隔离 MySQL 用例验证非零余额在十连和服务重启后仍可读取。
