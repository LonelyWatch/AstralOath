# 商店

主页「商店」、展开菜单「商店」和竞技场的商店入口共用 `ShopWindow.prefab`。返回时回到打开商店的页面。竞技场分类按录像使用两行横向滚动布局。商品顺序、名称、价格、货币发放数量、限购以及赛季目录内容来自 [竞技场商店表](../../../../Config/Shop/arena.json)。

`Res/Prefab/ShopItem.prefab` 是通用商品卡。商品名称、插图、次数、周期和按钮采用原布局 `shop_item_short.csb` 的坐标。`Scripts/ShopItemBinder.cs` 用服务端回执刷新剩余购买次数。普通商品使用绿色共用按钮显示货币与价格，赛季目录使用蓝色共用按钮居中显示「确认目录」。目录上方标示当前收录的装备数量。十一个目录共收录 66 条装备，打开和关闭目录均不产生交易。[目录数据来源](../../../../Config/Shop/README.md)

`GET /api/shop/arena` 返回征服点及商品列表。`POST /api/shop/arena/exchanges` 接受商品 ID 和本次兑换的请求 ID。扣点、限购、写入真实库存及操作记录在同一事务完成。行动力每次发放 40 点，强化石可直接用于相应装备或饰品。项目按 UTC+8 零点切换日限，每周一零点切换周限。

每个已登录玩家的导航会话持有一个 `ShopExchangeRequests`。同一商品遇到超时、断线、取消或无法识别的收据时，再次打开商店确认购买会复用当前请求 ID。收到有效收据或明确业务拒绝后，下一次主动购买才产生新 ID。凭此，服务端可以返回已经提交的兑换结果，避免重复扣点。等待中的请求由当前游戏进程和玩家会话持有。

原版商品位置及名称见用户提供的录像 02:13–02:16。所用商店背景、商品框、货币及商品图来自只读原素材，导入入口在 [ImportTowerShopArt.py](../../../../Tools/Arena/ImportTowerShopArt.py)。[实施及验收记录](../../../../docs/delivery/2026-11-28-arena-tower-shop.md)

商店顶栏显示征服点、金币和天空石。可从顶栏打开背包、邮件、聊天或快捷菜单。左侧八行及上方四个交易分类按原片布局，未开发入口共用功能提示。商品列表在最后一列预留原片可见的尾部间距。[分区尺寸、截图坐标与项目差异](../../../../docs/development/arena-shop-visual-revision.md)
