# 召唤

召唤确认弹窗允许点击材料不足的报价。余额不足时显示“材料不足”，保留弹窗和身后的结果页，玩家可以取消。多开导致服务端判定书签不足时同样提示并重新读取余额。十连结果的「再召唤一次」沿用上次的抽数、币种和价格，整个按钮都可点击。

获得演出的动态立绘和小人按实际投影像素选择渲染目标。结果横卡按每张头像的原始宽高等比放大 1.1 倍、右下对齐并裁切。通用规则同时适用于席可和宽头像。资产核对与实测见[本轮界面验收记录](../../../../docs/delivery/2026-11-20-home-and-arena-ui.md)。

主页「更多 → 召唤」打开 SummonWindow。SummonWindow 按 BindingMap 读取预制体节点，SummonWindowBinder 管理卡池、愿望单、弹窗、回执和演出。需要重新生成预制体时，运行 Unity 菜单「Tools → 游戏主页 → 生成召唤和神器」。

服务端 /api/summon 返回当前账号及区服的池版本、实际概率、货币和免费次数。提交时使用回执 ID 幂等重试。在收到已结算回执后才播放演出，用户随时可以跳过。再次打开时可查看上次结果，溢出的奖励在保管箱内领取。开发账号首次进入本区服发送测试票券。

配表与服务端实现位于 Server/Host/Summon。原版界面、骨骼、音频的路径和哈希见 Res/Textures 与 Res/Presentation 的 source-manifest.json，核对方法见原版召唤演出交付记录。

首次进入时优先显示已开放的伊赛丽亚概率 UP。誓约七人立绘、愿望单和十连结果以固定设计尺寸成组缩放。愿望单左侧同时显示七名英雄与七件神器，右侧每行五个候选。切换类别后仍可从左侧移除任一类别的选择。两个类别各选满七个时可以保存。

单抽、十连、免费气泡、愿望单与再次召唤各使用对应的普通态和按下态。价格底板使用源九宫格和线性色彩空间的透明度换算。中文字体与原布局指定的 daum.ttf 哈希一致，按钮、价格和标题分别使用对应字号与描边。愿望单可按持有情况、职业筛选，推荐列表取当前区服默认名单；有未保存的改动时显示确认按钮。

结果与揭晓分别独占整页；再次召唤的确认浮在结果之上。信息按钮默认显示注意事项，机率页按区服实际池分栏列出英雄和神器。齿轮打开本客户端的召唤设置，可切换卡池技能演示、查看最近回执。UP 召唤确认使用圆形战斗头像，首次获得英雄显示原版简中获得台词、日文语音及对应声优；重复获得可重听。顶部依次展示金光传承石、银河书签、神秘奖牌、誓约书签、天空石，保底与活动时间分别显示。

召唤及领取暂存奖励在写请求开始和完成时通知本次登录的库存缓存失效，下一次打开英雄或神器页会取权威结果，随后继续复用。免费召唤重置与卡池日期仍按服务端时间判断。[主页缓存复核](../../../../docs/delivery/2026-11-21-hero-layout-and-navigation.md)
