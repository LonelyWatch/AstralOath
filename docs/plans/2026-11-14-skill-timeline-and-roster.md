# 技能演出编辑器与百人阵容

## 技能编辑器

1. 从角色配表和角色实验室目录读取角色及技能映射。审计十名角色的动作、镜头、特效、画面、声音与源事件。
2. 复用 BattleSkillPresentation 编译时序并渲染预览。隔离场景、相机及骨骼。前进按固定步长推进，后退从起点重建。记录演出时间和停住源时钟的 Cut-in。
3. 窗口提供筛选、轨道、帧标尺、跳帧、拖拽定位、播放、缩放、节点参数检查。按图 ID 和源节点 GUID 保存局部覆盖。验证不改动生成图和战斗数值，过期覆盖报诊断。
4. 写测试证明覆盖不污染导入资源，改动时间能通过原播放器显示，关闭不污染正式场景。Windows Unity Editor 验收单列，导入与发布继续走现有路径。

## 逐角色扩充

以本地版本角色 ID 为排序基线，先确定可纳入的形态和缺失依赖。原有十名保留。新增角色逐个通过资产闭包、技能资料与配表、规则正反例、表现双向回放、源帧对照及入场测试后再更新计数。遇到缺失明确记角色、原始路径及验证情况。最终目标是 100 名已验角色，逐个到达门禁才计入。原作同版实机证据与当前播放器测试分别记录。

## 文件所有权

审计负责十人演出报告，阵容调查负责角色扩充操作文档，预览负责隔离视口会话。协调者负责图覆盖、编辑窗口、测试、文档入口和提交。
