# 战斗第三步实施计划

- [x] 核对游戏内帮助、官方变更和可复算数值，记录未证实的精确细节。
- [x] Shared Battle 以带版本、命令 ID 和序号的指令推进权威对局，输出有序事件、快照和胜负。覆盖无效命令、幂等重放、回合顺序和随机复现。
- [x] Luban 技能表增加有序效果行，涵盖三英雄九技能和强化参数。共享执行器根据目标、阶段和门禁产生伤害、恢复、状态、夹攻及追加攻击事件。

- [x] 服务端开放显式启用的双人对战验证入口，按房间串行处理，控制座位权限，支持按游标续接。
- [x] 核对 Luban、.NET、Unity 和实际双人 HTTP 流程，记录演出、装备和 RTA 赛季规则的剩余差异。
