# 战斗时序、连续性与试玩修订

用户已授权自主实施。主工程 main；视频/测量/截图放 D 盘 .artifacts，保留原作来源只读。

## 目标与设计

先测量再优化攻击入口及技能中主线程尖峰。读取同一版本原始 STG、骨骼事件、CUTIN 时长，按统一时钟复核安洁莉卡 S3 和首批九技能。夹攻表现于主攻击末击完成时开始，保留主攻击者的回位尾段，只有新动作拥有镜头；不改变服务端结算顺序。

自动进入本地试玩；显示实体真实 60 级史莱姆；暂停提供继续和重开并冻结表现/声音/输入；燃魂只由 Cancel 解除；行动条头像显示在大头像上层。保持 UIBaseView/Binder 与原资产 GUID。

## 工作与文件归属

- 性能：BattleSkillPresentation、BattlePreviewActor、独立性能测试。记录缓存前后入口耗时、首次与重复区别，避免运行时反复解析原文。
- 镜头：BattleCinematicStage、BattleSourcePostEffect、连续性测试；参考视频时间戳、源字段与推断写独立调查。
- UX：BattleHud/Binder/Preview、BattleTurnHud、编辑器菜单/预制体必要改动与独立 UI 测试。
- 协调：BattleSimulationPreview、BattleVoice、已有测试兼容、文档、Git；只有协调者运行 Unity，避免测试互相争用。
