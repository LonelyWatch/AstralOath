# 战斗第二步角色数据

目标是把拉斯、梅赛德丝和安洁莉卡的可溯源战斗数据放进现有 Luban 配置链路。

1. 固定一套等级、星级、觉醒与技能强化口径。核对英雄 ID、属性、数值、技能冷却、目标、魂力、强化与演出。版本或公式冲突进入复核记录。
2. 新增英雄、技能、技能强化与技能文案 CSV。沿用 CharacterLab 角色名键，技能使用独立稳定 ID；演出图与战斗命令分开。
3. 导表生成客户端单一快照、Luban 二进制和同源 C# 访问器。校验每名英雄三个槽、演出归属、图标、文案键、魂燃字段及强化连续性。可空倍率表示不适用或尚未取得一致证据。
4. 在隔离回归中改动源表、重跑二进制读回与快照同步，并验证错误槽位或演出不能发布。同步当前状态和下一步战斗规则验收。
