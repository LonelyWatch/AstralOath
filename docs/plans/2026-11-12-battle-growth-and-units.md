# 成长与战斗单位实施计划

目标是使用一份成长模板计算任意合法等级、星级与觉醒组合，并提供纯 C# 的战斗站位实体。

1. 用公开计算器的输入及历史公开实现交叉核对成长公式。保留原分组和两次取整，验证三英雄裸面板、逐级差、升星和觉醒。
2. 扩展 Luban，英雄只指定成长模板 ID。已录入的满档面板作为生成验收锚点。成长输入与觉醒节点由共享计算器验证。
3. 静态定义分英雄、怪物；运行实例统一。用队伍与槽号定位，怪物等级和面板由关卡提供，普通／精英／Boss 用等级类别表示。
4. 回归重复槽位与实例、英雄在敌方、同定义多个实例、怪物和英雄各自计算口径、生命值边界。导表验证三英雄锚点并拒绝无效模板。同步 ADR 与接手文档。
