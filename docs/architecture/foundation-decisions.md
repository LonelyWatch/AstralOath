# 地基决策记录

## 001 — 客户端与共享逻辑

保留 Unity 2022.3.62f3、URP 14.0.12、UGUI 和 TMP 3.0.7。客户端使用显式服务生命周期与 Binder；共享包纯 C#，netstandard2.1 同源给 Unity 与 .NET 服务端。新核心战斗行为需要兼容的程序版本，不能通过客户端 Lua 改写权威结果。

## 002 — 小规模部署与数据库

用户已选择 MySQL。服务端采用 .NET 10 模块单体、MySQL 8.4 InnoDB，初期无 Redis、消息集群或容器编排。云主机为 Windows Server 2022、2 核 4GB；100 人以内是目标规模，实际容量取决于后续战斗负载、数据库和带宽测量。编译与 CI 不在生产主机上执行。数据访问兼容性实测与显式 SQL 的取舍见 server.md。

## 003 — 配表与更新

Luban 管理源表、校验及生成；当前演示使用 CSV，后续普通策划表可用 Excel，但每张表只能有一个权威编辑源。复杂效果结构可用 JSON，不能让两个格式分别修改同一张表。配置、Lua、资源发布物统一经签名清单验证，YooAsset 负责 Unity 资源运行时加载。

客户端只在启动/安全切换点激活版本，失败保留有效版本。内核、协议、数据库不兼容时维护更新；数据库回退不能跟着资源指针自动降级。真实账户和战斗过程不进入首次地基演示。

## 004 — 插件边界

DOTween 使用免费版，通过项目动画服务隔离，逻辑结算不挂到动画完成回调。xLua 固定 Lua 5.3 原生 ABI，当前桥接采用明确的原始值 DTO 与导出列表，不开放全量 C# 热修复。MCP 是开发工具，不是客户端插件或服务端运行依赖。

嵌入包记录两处本地适配：Unity MCP Runtime 帮助程序集限定 Editor，并从 Editor asmdef 移除未安装的可选 Roslyn 引用；默认不定义 USE_ROSLYN。YooAsset 排除未采用的 Samples~ 和样例声明。原始库源与项目扩展分开，升级需重新跑兼容测试。

xLua 的托管程序集命名为 XLua.Runtime，避免 Windows 上与原生 xlua.dll 大小写冲突；命名空间保持 XLua。DOTween 免费运行库连同官方 Modules 导入，新增模块 asmdef 引用 UGUI，确保运行时模块初始化与裁剪保留可验证。

## 005 — 平台、文本与资源

横屏，1920×1080 参考尺寸；背景可铺满，交互元素限制在 Safe Area，平板与 PC 可调整布局。Windows 窗口可缩放；最低目标 Android 10/ARM64。界面语言 zh-Hans，语音 ja，二者独立；字体缺字必须有可见回退与可定位日志。

源图片保留质量，Android 使用独立 ASTC 与 ETC2 构建产物，Windows 使用适合透明度与内容的压缩；不能仅改资源标签就假定不支持 ASTC 的 GPU 可正常显示。UI 默认关闭 Read/Write 与 Mipmap，图集按窗口/生命周期拆分；滤波、PMA 和透明边缘需要视觉检查。声音按短音效、长语音/音乐分别设定加载策略，原作 FMOD bank 转换与播放保真度留到资源接入验收。

## 006 — 开发与交付

模块独立、Common 不依赖业务模块；依赖版本固定。AI 遵守根 AGENTS、模块文档、失败测试、独立审查、可复现验证和分支提交流程。原始解包目录只读，资源按已实现模块闭包引入。国际服只手动追踪。首次交付推送开发分支，不自动合并 main 或部署生产。
