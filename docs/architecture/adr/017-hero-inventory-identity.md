# ADR 017：区服英雄归属按实例持久化

日期：2026-11-18。状态：已采用。

每个区服玩家的背包有一条容量记录。每只英雄用独立实例 ID 关联当前背包和英雄模板，星级、等级和获取顺序存于实例。两个实例可以指向同一模板，各占一格。模板目录继续提供名称、属性、职业与原画。当前默认容量 1000。

复用账号选服会话和存量访客会话。所有持有查询从服务端认证得出归属，不接受客户端指定其他玩家。正式账号选服时初始化；旧账号或测试访客首次查看时也可初始化。服务端在同一事务内基于玩家锁和背包头记录一次发放，保留既有邮箱校验与密码哈希。后续加入产出与消耗时必须在事务内检查容量并写入权威审计。

首版只有读取接口。装备、神器分页空置。同模板持有与现有模拟战选禁目录互相独立。UI 与资源通过现有 Home 业务程序集和 YooAsset 热更，服务端与 MySQL 迁移分别发布。

实施和验收见[英雄背包系统制作方案](../../plans/2026-11-17-hero-inventory.md)。
