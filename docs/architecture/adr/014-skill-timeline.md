# 技能演出编辑数据与预览时钟

技能编辑器使用独立 EditorWindow 及隔离预览场景，复用 BattleScene 的演出播放器。既有 STG 图包含有向边、命名事件、分支、附属时间轴与暂停源时钟的 Cut-in。保持该模型，时间轴从实际编译节点读取，避免两套时序解释器。

原图由导入器维护。按图 ID、源指纹及节点 GUID 记录项目覆盖，保存显式源时间和演出参数。发布时作为战斗场景的 TextAsset 依赖交给播放器。不改权威事件、角色数值或原始来源。预览向后定位从零点重新执行，声音独立暂停、停止与重播。

维护和验证见[技能演出编辑器](../../development/battle-skill-timeline-editor.md)。
