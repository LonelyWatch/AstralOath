# 原始资源与后续战斗验收边界

本记录继承实施前的只读资源审计。首次地基演示使用自建文本、开源字体和测试资源，没有导入原作角色或全量解包数据。

## 已观察到的内容

来源 `D:\sevenepic`，记录版本 `pack-15-r4262`。解包清单包含 91,428 个文件，共 9,544,160,577 字节；此前按清单逐项核对大小和 SHA-256，没有发现文件缺失、大小不符或哈希不符。这只证明解包输出符合该清单，不证明清单覆盖完整游戏。

角色与演出存在 SCSP、SCT、atlas、CFX、STG、timeline、CSB 等格式。1,299 个模型文件中观察到 Spine 2.1.27 和 3.8.99 两类版本；模型数不等于可用英雄数。667 个 timeline 与 2,554 个 STG 的 JSON 语法可解析，尚未验证运行时行为。日语语音以 FMOD bank 等形式存在，不能把 bank 直接当作 Unity AudioClip。

选人/禁用、双方五个位置、保护位、倒计时等界面资源存在；TFLite 推荐模型和 UI 布局不能代替服务端 BP 状态机、超时、断线和回放规则。数据库的大部分文件尚未形成可用字段映射。BattleLogic 名称和校验摘要不能证明已获得原始战斗函数实现。

## 仍需验证

- 游戏术语中文表尚需补充；日文文本不能被标注为官方中文。
- atlas 存在缺失引用，例如 Cecilia 部分旧效果、Salome、stageclear_base、waterfall 和 wheel；是否被当前版本实际调用需要映射验证。
- 少数 timeline/STG 固定效果名称未找到同名资源；部分动态模板需要运行时替换规则。
- SCT/SCSP 转换器能识别格式不等于所有角色、材质混合、遮罩、旋转和帧时序一致。Spine 运行时选型需基于实际转换样本决定。
- 原始技能倍率、触发优先级、结算顺序、AI 决策、随机数、BP 流程、技能演出和音画同步尚未完成原作对照。

## 后续验收方法

用户监督选择代表性角色和战斗录像，建立“源资源 → 角色/技能 ID → 配表 → 事件 → 演出轨道 → 音频”的可追溯链。先覆盖单体/群体、追加回合、反击/夹攻、复活/死亡、护盾/无敌、行动条、免疫/抗性、被动连锁等机制类别；同一初始状态、指令和随机种子验证重放一致，再逐项与原作表现核对。

BP 单独验收选边、先后手、预禁用、保护位、选人、最终禁用、超时、退出和重连；界面展示和权威状态分别核对。不将演示回显、接口存在或资源数量作为战斗还原通过证据。

版本更新只在用户明确要求追踪后进行一次审计，并保存输入清单摘要与差异。本项目没有持续追踪任务。
