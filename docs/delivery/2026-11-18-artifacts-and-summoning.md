# 神器与召唤首版交付记录

## 玩家入口

- 主页「背包 → 神器」查看持有、锁定、强化、突破与出售。主页「更多 → 英雄」从英雄详情配戴、替换或卸下，支持同名的独立实例。
- 主页「更多 → 召唤」进入常驻誓约与伊赛丽亚／星辰之歌 UP。界面显示服务端当前概率。常驻支持每日免费单抽、誓约或史诗书签及七名英雄加七件神器的愿望单。UP 支持单抽及十连，连续 120 抽未得伊赛丽亚后下一抽保证。
- 本机开发环境的英雄详情提供「神器试战」。开局锁定真实等级、配戴和配置版本，操作由权威战斗服务处理。当前客户端取所选英雄单人出战，服务端接收一至四个持有实例。对手为同等级的已有战斗角色。
- 新开发账号每区服一次发放 60 誓约书签。英雄和神器分别使用 1000 与 400 容量，溢出可到召唤保管箱领取，保管箱容量为 400。

## 数据与素材

- 神器目录为 22 件三星、12 件四星、8 件五星。中文描述取自项目固定的原版文本版本，每件配套原版横版列表、完整竖卡与战斗提示图标。公开的数值与配置出处详见 [评审方案](../plans/2026-11-18-artifacts-and-summoning-review.md)。
- 强化的等级经验表、喂食基础经验、金币成本和出售金额在开发配表中明确配置。现有原版资源无法直接读出对应的原版经济表，这些数值仍需实机采样核对。常驻测试池合并了当前无可用候选的三星、四星月光权重，概率页按真实配置展示，五星月光保留独立分组。
- 常驻页使用原版 gacha_wish_bg_2/3、斜向遮罩和愿望单边框。UP 页使用伊赛丽亚对应的 gacha_c1024_01_bg 与 gacha_c1024_01_banner、原版骨骼立绘和星辰之歌整卡。原版旧背景左侧带有预合成的神器卡，新布局截取其森林区域，并把独立原版神器卡放在右侧。
- UP 页在展示立绘 3.25 秒后淡出海报，播放伊赛丽亚原版 S3。保留从战场起手到特写、终击和回场约 11.2 秒，仅裁除尾部待机。卡池操作留在预览上方。查看弹窗时暂停，换池或退出时重置。图像使用原技能时间轴的单目标渲染，播放端以图集解码复用现有图形 API。音轨使用原 FMOD 技能音效与两条原版日语语音。
- 主抽卡演出使用原版翻书、走廊、六职业与神器雕像、蓝／金／紫光、抽卡揭晓与结算。FMOD 事件、画面帧与资源哈希详见 [原版演出核对](2026-11-18-native-summon-presentation.md)。
