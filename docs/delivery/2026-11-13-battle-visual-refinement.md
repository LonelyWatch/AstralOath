# 战斗光效、绮世 S3 与回合反馈

## 来源与定位

- 赛西莉亚「毁灭之枪」S3 中，模型 `skill3_2` 的 timeline 触发 `cecilia_skill_03_new_lance2`，使用 `cecilia_skill_03_lanceaura2` 的 `lance_global_glow/flash`。该槽约在局部 1.53 秒放大到约 16 倍，再由骨骼染成紫色。原 SCT1 以 RGB565 存颜色，A8 单独存透明度。暗边实测 A=5、RGB=(0,4,0)，在黑幕和紫色染色下形成绿边与色阶。Unity 已用双线性和 Windows RGBA32。恢复赛西莉亚 5 张图集内 20 个审核过的白色 PMA 区块的 RGB，保留透明度和同页彩色素材，清单记录每个区块及源、输出哈希。没有更改运行时 shader。
- 绮世「夜曲」S3 的原 `c_kise_skill_03.stg` 中，#2/#9/#13 的 EFFECT 未声明 `location` 或 `locationParam`，带 `y=216`。前景遮罩和两张背景板原先随受击者平移并继承其大小，换站位会改变布景；源图另有 `screen_pivot` 节点轨。现在这组屏幕 CFX 与屏幕节点按镜头取景重投影并保留震动和层次，显式世界坐标仍按各自锚点执行。技能中途的地图隐藏和恢复来自源 BGSHOW。其他省略位置的情况保留诊断，新增角色按源证据确认。原星空图集也存在同样量化问题，经审核恢复 11 个中性光环及白色光效区块，保留星空和彩色背景。首次命中时施法者会按源节点短暂穿出视口下缘，第二次命中双方可见，原版对应帧尚待实机对照。`y=216` 是已核对的签名，未推断其余省略值的完整原生语义。
- 用户提供的 10:38 附近截图显示红色损血尾层、黑色角色轮廓及仍可见的头顶状态。视频地址访问返回 HTTP 412；本次直接使用附件和前次留存的 E7WC 官方画面核对死亡阶段。[用户参考视频](https://www.bilibili.com/video/BV1qdYMzXEtt/?t=638) · [官方比赛死亡片段](https://www.youtube.com/watch?v=cIn1sX4JNTU&t=3039s)

## 表现规则

- 三个 Buff 排在贴近血条的首排，从第四个起向上折行；按原状态顺序复用，移除后重新紧凑排布。持续数字和图标随角色及镜头同步。
- 十名已导入英雄都有 `b_idle`、`b_idle_ready` 两套有效循环。由已呈现的回合选择目标循环，技能/受击/镜头控制期间保持姿态，动作尾端用既有混合回到对应待机。缺有效 ready 时沿用普通循环。安洁莉卡及梅赛德丝的额外待机附属演出未计入本次骨骼验收。
- 已接受的伤害按源命中时点逐段表现受击、护盾和飘字，在最后一段将已接受的整笔生命损失交给血条主层和红色尾层。全额护盾吸收只动护盾。一次行动的视听播放不修改权威血量或协议。
- 已接受击倒时，由现有的源受击动作接力，否则用该模型的 `attacked`。十名模型均有受击动作、没有单独的死亡骨骼动作；另查到 `effect/die.scsp` 是共享独立效果，暂无证据表明它负责这些英雄的身体姿态。采用 0.20 秒黑化、0.12 秒黑色剪影停留、0.28 秒淡出，属于项目的暂定表现时长，身体阶段仍合计 0.60 秒。剪影完整显示后才放粒子。黑化与停留时保留完整身体和头顶状态，淡出时同步衰减，粒子尾迹单独播放。镜头源遮挡、暂停、重开及同帧复活各自保持原所有权。

## 验证

- 修改前复现：三列测试第 4 个图标错误地留在首排，白光图集低 alpha 像素存在色偏，多段第二击提前改变显示生命，死亡开始后受击骨骼的播放时间停在 0。
- 最终针对性 Unity PlayMode 11/11。覆盖 30 个已导入技能图、绮世在两种目标站位下的屏幕锚点与地图复位、八人场景待机、五个图标排布、多段盾与 HP、暂停、死亡退场及同帧复活。死者在 0.28 秒的场景截图中仍有完整剪影、红色损血尾层和减益图标。
- 本机 D 盘可查 `.artifacts/visual-refinement/death-028.png`、`death-039.png`、`status-wrap-three.png`，以及 `.artifacts/ten-hero-frames/source-playback/` 下的 `kise-s3-cinematic-*.png`、`c1006-s3-hit-1.png` 和 `cecilia-s3-lance-glow.png`。源图诊断帧隔离了实战演出驱动，固定的测试 HUD 只作环境参照；角色头顶状态跟随另由实战用例验证。
- 最终 Unity EditMode 480/480；其中 12 个待机测试、3 个真实图集区域测试、19 个死亡呈现测试。Python 角色导入 49/49，923 项资源清单验证通过。六张改动贴图的全部 alpha 与区块外像素另逐字节与解包数据核对一致。Windows IL2CPP 和 Android 包本轮未重新构建。
