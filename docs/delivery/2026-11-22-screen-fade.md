# 全屏页面的黑幕转场

## 原版取帧

国服本机录屏 `Screenrecorder-2026-11-17-22-21-00-778.mp4` 的 00:06.373–00:08.019 是从大厅快捷菜单进入英雄页。用 FFmpeg 从 2608×1200 的录屏取连续解码帧，再缩到 160 像素宽测量整帧亮度。00:06.373、06.455、06.496、06.578 和 06.619 的 Y 平均值依次是 94.4、76.7、62.7、29.5 和 16.0。视频黑电平为 16。黑画面持续至 07.607，07.648 出现英雄页蓝色背景，随后演员和控件显现。不同页面内容的亮度不同，不能从整帧均值准确反推单一遮罩的透明度。录屏的游戏版本、发布日期和播放倍速未确认。

同日 `Screenrecorder-2026-11-17-22-28-01-55.mp4` 的 00:02 左右从英雄页点顶栏背包，采样未见一段相同的全黑停留。两组画面在本机 `.artifacts/black-transition/hero.jpg` 与 `bag.jpg`，详细亮度及时间戳在 `means.log`。在工作区重新取样可用 FFmpeg 的 `scale=160:-1,signalstats,metadata=print:key=lavfi.signalstats.YAVG` 滤镜。

## 导航接入

登录进大厅的等候黑幕和大厅快捷菜单进英雄页共用 `ScreenFadeTransition`。导航层在账号生命周期中持有一份全屏 Canvas，平时隐藏。调用 `RunAsync` 时，黑色遮罩约用 0.24 秒盖住旧页，再执行页面切换，待新页准备好后约用 0.20 秒显现。全黑时长由实际资源和账号数据的准备进度决定。0.20 秒是按新页面的显现节奏选取的项目参数。动画按未缩放的时间推进。输入拦截、键盘焦点、等待中的切页和退出登录的清理都由转场维护。背包入口及页内确认窗沿用原有显示行为。

转场位于 FoundationDemo 热更程序集。它只接受异步换页回调及取消令牌，既可包住 `WindowCoordinator` 的整页切换，也可包住第一次准备主页的异步操作。遮罩没有全局单例。

## 检查结果

Unity 2022.3.62f3 Windows D3D11 PlayMode 的 `HomeStartupPreparationTests` 通过 12/12。旧版先因没有可渐变的 CanvasGroup 在取消登录用例失败。改后实测游戏时间暂停时进出黑幕各有中间帧，账号响应延迟时保持全黑，失败或取消后黑幕被清理，从大厅进入英雄页复用同一遮罩。报告保存在本机 `.artifacts/black-transition/red.xml` 和 `green.xml`。
