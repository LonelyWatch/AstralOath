# 第 61–70 名英雄交付记录

固定简中英雄索引的第 60 名为菲奥雷托，第 61 名为迪埃妮，第 70 名为薇薇安。本批按实际存在的普通角色 ID 排列，沿用 pack-15-r4262 的角色、技能、技能组、状态及简中文案。运行 `Tools/CharacterAssets/ExportRosterQueue.py`，读取输出清单中 ordinal 61 至 70 的条目即可复核顺序。已用仓库登记的脚本重新验证这十项均为 configured。 [官方英雄索引](https://static-pubcomm.onstove.com/gameRecord/epic7/epic7_hero.json)

## 角色及原版分支

61. 迪埃妮（c1076）。S1 自身已有强化时再提升一次速攻。S2 以每个友军自己的最大生命计算护盾。S3 驱散全体弱化，觉醒后增加穿透抵抗，燃魂将自身各技能的冷却减少两回合。
62. 洁若米亚（c1079）。S2 重置 S3 并给予额外回合，觉醒时获得攻击力大幅提升。S3 固定防御穿透 50%，燃魂攻击倍率从 1.15 升至 1.65。
63. 帕贝尔（c1080）。三个攻击各自按施法者速度增伤。S2 觉醒加攻在命中前生效，且禁止反击。S3 根据目标身份忽略伤害分摊，精英与首领仍可分摊。
64. 赛瑞丝（c1081）。S3 冷却中，S1 从可参加的队友中随机选择夹攻者。S2 燃魂无视效果抗性。S3 用有利属性进攻、缩短强化并分别判定降速与束缚。
65. 璐璐卡（c1082）。S1 根据目标失血比例增伤。S2 护盾取施法者攻击力的 40%。觉醒 S3 的隐藏攻击加成每次 20%，最多三层。
66. 杰诺（c1083）。S2 通过状态表降低敌方回避，在自己回合开始时检查敌方是否有冻伤。这个被动没有单独 STG。S3 在自身狂气时无视效果抗性，破裂的额外伤害取目标最大生命的 12%。
67. 卡瓦朱（c1085）。S1 的 35% 追加行动复用第二槽动作，提升自身速攻 20%。受击后的被动会解除弱化、给予攻击提升，并使用单独的冷却。
68. 卡瓦娜（c1086）。S1 两个出血各自判定，觉醒后对处于弱化的目标追加伤害。S2 的技能伤害无效及 S3 的速攻提升逐个检查队友是否为火属性。
69. 尤贝乌斯（c1087）。S2 全队暴击率提升，觉醒后追加自身回合。S3 防御降低从基础 80% 按强化提升，燃魂的攻击倍率为 1.95。
70. 薇薇安（c1088）。S2 击杀后才进入下一段。原技能指针依次指向隐藏第 4、5 技能，它们沿用第二槽动作，攻击倍率分别为 0.55 和 0.30。场上仍须有活目标才能继续。
