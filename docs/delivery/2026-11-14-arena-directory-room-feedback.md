# 模拟战目录、房间与点击反馈复核

依据本地 `wnd/pvplive_base.csb`、国服录屏 `Screenrecorder-2026-11-14-21-34-41-148.mp4` 和用户提供的目录、房间截图。目录的创建按钮从原版 `_btn_gold` 原图派生独立九宫格，更新目录使用原版普通／按下的 `_btn_small_black` 切边。根据截图校正字宽、图文落点、按钮间距和灰色亮度。两条分隔线使用 `_bar_2` 的空心菱形、各自透明度。右栏继续只提供模拟战，选中图 `_select2` 的左侧切片保留固定宽度。

房间按截图加入半透明区域，排列锁标识、对阵头像与徽章。自己的对阵名、成员名与聊天名都追加 [me]。聊天使用原版相对时间格式，放在昵称后并限制长昵称宽度。成员区使用从上到下再向右的列优先排列，发送记录按消息时间顺序留在同一滚动列表。当前游客身份只包含显示名和头像，界面不会显示虚构公会、大区、房间设置值或可用开战状态。

点击光环从原版点击序列采样并结合 `pati_03` 粒子重建。光环打开后呈细边，淡退时保留几颗粒子。同一 Canvas 复用最多 10 个效果。录屏波形核对的三组通用音色如下。

- 返回、取消使用 `event:/ui/msgbox/btn_cancel` 对应的 UiCancel。
- 普通点击、确认、关闭浮层使用 `event:/ui/btn_normal` 对应的 UiConfirm。
- 用户触发但无法执行的动作使用 `event:/ui/popup/down_neg` 对应的 UiBlocked。有校验的提交由业务在结果明确时播放一种反馈音。

`Common/Res/Prefab/GameToast.prefab` 复用原版底栏蓝边 `_cm_popnoti_bg.png`，提示不接收输入，后续提示刷新计时，关闭所属界面时清理。录屏约 7.4 秒的入场密码面板由 ArenaPasswordEntry 独立预制体实现，外部点按关闭。格式或服务器密码校验失败保留面板并显示提示，校验通过后入场。创建房间字段错误也走同一提示。房间尚无开战入口，一人时提示没有玩家，有对手时提示当前无法开始。聊天区反馈条与跨界面的底栏提示属于不同位置。

本轮包含 Common 运行时代码与首场景音源配置，随新母包发布。Arena 原有地址保持，密码和提示由页面预制体引用。

Unity EditMode 6 项及图形 PlayMode 8 项通过，包括两会话建房及锁房入场、拒绝错误密码、底栏提示、[me] 和刚才、聊天收发、细环尾段粒子及禁止点击。目录和房间资源检查为 84 项 Arena 与 27 项 Home。实机截图作为对照，手机真机与在线战斗未在本轮测试。

房间遮罩后续复核使用同一张 21:39:08 实机截图。旧版本仅在上方 9.5% 高度放置灰条，成员区蒙版 alpha 为 53/255，压暗不足。顶部换用 `pvplive_lounge.csb` 的原版 `_grow_s` 黑色渐变，其可见部分渐隐至画面约四分之一处。成员区从金色分隔线至底部使用半透明黑底和原版 `_grow` 柔化，层级位于头像、姓名和控件后方。原版 `pvplive_spectator_bar.csb` 卡片高 76，房间列表高 256，对应每列三人。客户端按服务端入场顺序从左上向下取三人，再从下一列顶部继续，横向可滚动。

在同一 1920×900 截图坐标采样，成员区背景平均 RGB 从 85 降到 35，原版参考为 26。底部从 40 降到 9，原版为 9。画面背景构图有差异，数值用于核对整体压暗幅度。Unity 图形回归实测四会话入场顺序与坐标，第一至第三名在第一列，第四名在第二列顶部，并采集 1920×900 与 1600×900 的截图。

按后续截图反馈复核遮罩外形。移除成员区均匀的黑色矩形，改为单层原版 `_grow` 黑色光晕。该贴图在横纵两轴均从中心向外渐隐，光晕起点上移到分隔线之前，局部延伸到画面边缘之外。规则文字背后的遮罩也改用该贴图。成员光晕沿用原版垂直范围，横向范围和叠加浓度按当前 Unity 庭院调节。
