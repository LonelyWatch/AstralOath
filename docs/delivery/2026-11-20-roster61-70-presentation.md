## 查到的表现原因

- **受术队形没有横穿赛瑞丝的蓝束。** 播放器以前丢弃所有 `NODE_ANI target_node=76`。固定包中有 149 条这类节点，艾莲西雅 S3 的源 id 明写 `teamtarget`，赛瑞丝 S3 #26 使用 `ceris_sk3_2eff_node_target`。原片 19:46.54–47.02，三名受术者随蓝束向左横移。在 520 像素宽的对照中，平常两侧对手相距约 96 像素，此时仍相距约 91 像素：镜头放大两倍，源骨骼同时将队形缩至一半。旧播放在双朝向的首个关键点实测都为 0；源位移应为 ±17.9693 个世界单位。修复同时移动队形中心及身体间距，原站位和无关角色保留。源 3.0 秒的蓝束上已出现整组目标。对照图见 `references/c1081-target-before-after.jpg`、`references/c1081-targets-spread.jpg`。
- **赛瑞丝的魔法阵开在对手身旁。** 原片 19:43.7–44.2 的蓝色法阵圆心始终包围施法者。#21 与 #22 同时从 #6 的开始边发出，#22 指定施法者的 `*_node_self` 骨架，#21 CFX 的前后景均取自这套特效。旧程序按敌方主目标安放，双向原点回归测出 -4/+4 互换。现按共享的源骨骼名族与开始边选择起手位置。把 #22 人为错开 100 ms 后，测试仍按原位置 5 的主目标处理。#26 同时要求在 567 ms 切 `attacked_damage`：对实际零时长的受击骨骼，显示此单帧姿态，直到节点或下一个姿态接管。具有运动轨的第三字段 0 单列为未核实。
- **迪埃妮、尤贝乌斯、薇薇安暗场中出现无关角色。** 固定包中 211 条 55 号零透明身体层含多条 `cb_without_self`、`cb_withoutself`、`wo_self` 的命名；原片的三个起手都只见施法者。迪埃妮 #9 淡入 250 ms，由 #12 立即释放；尤贝乌斯 #22 淡入 200 ms，#23 STOP 的 200 ms 与层的淡出时长一致；薇薇安 #16 淡入、淡出各 200 ms，在 2666 ms 开始恢复。修复前三人淡入中点的同队与对手全为 1，源曲线为 0.5。
- **薇薇安的金色光柱。** 原片 20:42.5 有光柱罩住己方。旧实现仅给修尼尔的文件放行 `EFFECT location=32`，导致薇薇安 #18 被跳过。在全部 217 张图中仅两张图的 EFFECT 使用此位置：修尼尔 S2 #9 九层，薇薇安 S3 #18 三层 Spine、外加 700 ms 延迟的粒子。现在按己方阵型中心只生成一套。修复前薇薇安两侧为 0 层，两角两侧复验 4/4 通过。

## 实战采样口径

通过真实布阵入口开十场战斗，各自核对头像和三栏技能并提交基础攻击。然后在同一个 BattleScene 用固定阵位依次播放每份 STG，按 30 fps 推进，保存每个独立命中、立绘中点、S3 的半秒阶段及回位。十份立绘依源 WebP 的逐帧时长播放，九份有变帧长，薇薇安为 30 帧、每帧 60 ms。直接回放夹具的左下角沿用拉斯，真实阵容及权威后续攻击、状态的图片使用各自的实际 HUD。普通形态原片和工程背景、敌方模型、录像 HUD 不同，核对时按施法动作、可见队形、法阵中心和进出场顺序对齐。

- **迪埃妮、洁若米亚、帕贝尔。** 迪埃妮的蓝色流光、金鸟及金光祈愿依序出现；洁若米亚的普通形态铠甲、火剑和右行火狮可辨；帕贝尔的蓄枪绿弧、披风持枪近景、绿色狼首、连续命中及白闪均有对应阶段。
- **赛瑞丝、璐璐卡、杰诺。** 分别检查法阵相对施法者的左右位置、冰流与受术队形；水晶、蓝色球体、紫色立绘和粉白轨迹；暗场浮起、红阵巨口与红场爆发。璐璐卡起手两侧冰峰阶段仍能看见工程目标，原片主要出现施法者及冰峰；其 STG 具有缺省类型透明层、具名短时 66 和目标色调，应继续与实际阶段交叉验证。
- **卡瓦朱、卡瓦娜、尤贝乌斯、薇薇安。** 金焰蓄拳转红金交叉线；脸谱木桩、金发弯刀、落地爆裂；手弩、火矢及沙尘命中；紫色天空、闪光和队伍金柱。卡瓦娜原片早段红幕上白底脸谱的阶段与工程半秒采样能对应，局部背景的红橙色调仍存在差异。尤贝乌斯的工程尾段有较长的散烟与黑场，原片剪辑未提供同场地、同倍速边界，不能由此推算毫秒误差。

### 杰诺 S3 的受术者飞行动作

固定源 `c_zeno_skill_03.stg` 的节点 25 在巨兽 CFX 开始时启动，`target_node=76` 选中受术队形，`0,flying,0` 指定立即切到每个受术者自己的 `flying`。对应队形骨 `zeno_sk3_node.scsp` 在 0 至 2.5 秒维持零位移、单位缩放。原服普通形态实录 35:57.7–35:58.2 能看出目标在巨口上方，后续被巨兽和爆光遮住。视频取样与倍速见本页开头。只读统计 r4262 的 STG，有 19 个 `flying,0` 条目和 35 个 `flying,1` 条目；这两类时点都明确指定原生动作，能从受术者骨架确定第一遍的姿势变化。

十人 PlayMode 的对手是亚敏。她的 `arming.scsp` 提供 0、100、166.6、233.3、333.3 毫秒五组飞行关键帧。旧播放器在正常出手和回放均跳过整项，0 毫秒仍是 `b_idle`。修复后选取右侧裙甲骨 `armor_skirtlow_r`，前三个时点分别与原生 Spine 独立采样对照，动作旋转键依次为 −7.56°、−11.02°、−14.48°。受术者只由技能时钟推进一次；首遍后把姿态交回常规受击/待机，原队形节点按自己的 2.5 秒寿命释放。首遍结束后的原服循环、保持与退出行为仍无定论，这里的交接是本项目回退。

失败证据与专项结果保存在 `.artifacts/roster61-audit/zeno-flying-{red,final}.xml`。验收覆盖正常完成、提前结束、新受击轨接手、另一种未识别的动态零标志条目，以及赛兹既有的四段受击轨。联跑中的三条 `Fire` 未识别动作来自阵容预热的亚敏 S2、赛西莉亚 S2 和维德瑞 S1。

总图和逐人原片时序、S3 半秒图、实际后续动作都已目检。最终前后图可见迪埃妮与薇薇安起手独自留场，尤贝乌斯发射火矢时右方的无关身体已隐藏；赛瑞丝 2.0 秒法阵包围施法者，3.0 秒蓝束上可见受术队形。薇薇安 3.0 秒光柱起爆，3.5 秒光柱及金环仍在己方，4.0 秒出现散粒。`.artifacts/roster-61-70/battle-review.jpg` 为十人总图，`battle-variants.jpg` 为实际分支与状态，`references/visibility-and-effects.jpg` 为同一源秒修前与修后图。

## 单目标镜头补充核对

全量复播暴露了 CAM 的 `location=2` 未映射。扫描已接入的 217 张图共出现于 13 图、47 个节点，本批四张单体图占 13 个。分别为洁若米亚 S3 #17、20，赛瑞丝 S2 #15，卡瓦娜 S3 #6、18、20、22、24、28、30、32，尤贝乌斯 S3 #17、31。旧播放器回退到初始镜头位置，即使目标换槽或移动，焦点仍留在场心。

卡瓦娜 S3 #6 的 CAM 与 #7 的目标特效横向偏移均为零。黑铁 2025-10-03 日服普通形态片段中，19:31.7–33.2 脸谱居中连续上升，19:35.7–36.2 爆裂落在针对同一人的画面中央。尤贝乌斯普通 S3 先拍发射者，接着 #31 对目标施加 y=-60 的平移；20:13.4–13.9 可见火光及受术者。视频 30 fps，画面无可读的播放倍速。赛瑞丝这次补核的是 S2 源节点，没有用于断言 S2 的独立原片。只读取了固定包图和原片，原始 CAM 位置枚举未取得可读命名。[卡瓦娜实录](https://www.youtube.com/watch?v=8PPBeDcevjg&t=1171s) · [尤贝乌斯实录](https://www.youtube.com/watch?v=8PPBeDcevjg&t=1212s)

实现使用开演时唯一受术者的实时位置，保留每张图自己的偏移、时长及曲线。独立 Unity EditMode 直接读取四张正式源图，旧场心回退让四个用例各偏离期望 5 个测试场景世界单位；修正后四图都在双向站位、移动与镜头复位检查中通过。另两例验证初始双受术者和开演后失去第二人仍保留群体诊断。专项合计 6/6，记录见 `.artifacts/roster61-audit/camera-two-red.xml` 与 `camera-two-green.xml`。实际结算若只把唯一幸存目标传给播放器，会按单人演出处理；多个受术者同时在场时的 CAM 2 原版取景仍待验证。

图形镜像于 19:41:22、19:41:26 分别写出卡瓦娜、尤贝乌斯的新 S3 轨迹。卡瓦娜源 4.0 秒镜头从 (0, 2.563) 移至 (2.805, 0.568)，木桩金线由画面约 60% 宽处移至中线，第七次命中的光核上移后脱离底部技能栏。尤贝乌斯源 4.0 秒从 (0, 1.074) 移至 (2.805, −0.921)，受击爆点回到画面中央附近，最后一次 HIT 与受术者处于同一位置。两者变焦值分别保持 7.668 和 4.542。洁若米亚及赛瑞丝的重新采样也检出同一受术者的水平位移。四个镜头最终全部回到 (0, 0)，正交尺寸 5.4。前后逐帧对照见 `.artifacts/roster61-audit/camera-two-battle-comparison.jpg`，本轮十人实战复播 5/5，日志中该位置警告为零。
