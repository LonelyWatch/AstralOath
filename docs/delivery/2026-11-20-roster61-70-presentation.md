## 查到的表现原因

- **受术队形没有横穿赛瑞丝的蓝束。** 播放器以前丢弃所有 `NODE_ANI target_node=76`。固定包中有 149 条这类节点，艾莲西雅 S3 的源 id 明写 `teamtarget`，赛瑞丝 S3 #26 使用 `ceris_sk3_2eff_node_target`。原片 19:46.54–47.02，三名受术者随蓝束向左横移。在 520 像素宽的对照中，平常两侧对手相距约 96 像素，此时仍相距约 91 像素：镜头放大两倍，源骨骼同时将队形缩至一半。旧播放在双朝向的首个关键点实测都为 0；源位移应为 ±17.9693 个世界单位。修复同时移动队形中心及身体间距，原站位和无关角色保留。源 3.0 秒的蓝束上已出现整组目标。对照图见 `references/c1081-target-before-after.jpg`、`references/c1081-targets-spread.jpg`。
- **赛瑞丝的魔法阵开在对手身旁。** 原片 19:43.7–44.2 的蓝色法阵圆心始终包围施法者。#21 与 #22 同时从 #6 的开始边发出，#22 指定施法者的 `*_node_self` 骨架，#21 CFX 的前后景均取自这套特效。旧程序按敌方主目标安放，双向原点回归测出 -4/+4 互换。现按共享的源骨骼名族与开始边选择起手位置。把 #22 人为错开 100 ms 后，测试仍按原位置 5 的主目标处理。#26 同时要求在 567 ms 切 `attacked_damage`：对实际零时长的受击骨骼，显示此单帧姿态，直到节点或下一个姿态接管。具有运动轨的第三字段 0 单列为未核实。
- **迪埃妮、尤贝乌斯、薇薇安暗场中出现无关角色。** 固定包中 211 条 55 号零透明身体层含多条 `cb_without_self`、`cb_withoutself`、`wo_self` 的命名；原片的三个起手都只见施法者。迪埃妮 #9 淡入 250 ms，由 #12 立即释放；尤贝乌斯 #22 淡入 200 ms，#23 STOP 的 200 ms 与层的淡出时长一致；薇薇安 #16 淡入、淡出各 200 ms，在 2666 ms 开始恢复。修复前三人淡入中点的同队与对手全为 1，源曲线为 0.5。
- **薇薇安的金色光柱。** 原片 20:42.5 有光柱罩住己方。旧实现仅给修尼尔的文件放行 `EFFECT location=32`，导致薇薇安 #18 被跳过。在全部 217 张图中仅两张图的 EFFECT 使用此位置：修尼尔 S2 #9 九层，薇薇安 S3 #18 三层 Spine、外加 700 ms 延迟的粒子。现在按己方阵型中心只生成一套。修复前薇薇安两侧为 0 层，两角两侧复验 4/4 通过。

## 实战采样口径

通过真实布阵入口开十场战斗，各自核对头像和三栏技能并提交基础攻击。然后在同一个 BattleScene 用固定阵位依次播放每份 STG，按 30 fps 推进，保存每个独立命中、立绘中点、S3 的半秒阶段及回位。十份立绘依源 WebP 的逐帧时长播放，九份有变帧长，薇薇安为 30 帧、每帧 60 ms。直接回放夹具的左下角沿用拉斯，真实阵容及权威后续攻击、状态的图片使用各自的实际 HUD。普通形态原片和工程背景、敌方模型、录像 HUD 不同，核对时按施法动作、可见队形、法阵中心和进出场顺序对齐。

- **迪埃妮、洁若米亚、帕贝尔。** 迪埃妮的蓝色流光、金鸟及金光祈愿依序出现；洁若米亚的普通形态铠甲、火剑和右行火狮可辨；帕贝尔的蓄枪绿弧、披风持枪近景、绿色狼首、连续命中及白闪均有对应阶段。
- **赛瑞丝、璐璐卡、杰诺。** 分别检查法阵相对施法者的左右位置、冰流与受术队形；水晶、蓝色球体、紫色立绘和粉白轨迹；暗场浮起、红阵巨口与红场爆发。璐璐卡起手两侧冰峰阶段仍能看见工程目标，原片主要出现施法者及冰峰；其 STG 具有缺省类型透明层、具名短时 66 和目标色调，应继续与实际阶段交叉验证。
- **卡瓦朱、卡瓦娜、尤贝乌斯、薇薇安。** 金焰蓄拳转红金交叉线；脸谱木桩、金发弯刀、落地爆裂；手弩、火矢及沙尘命中；紫色天空、闪光和队伍金柱。卡瓦娜原片早段红幕上白底脸谱的阶段与工程半秒采样能对应，局部背景的红橙色调仍存在差异。尤贝乌斯的工程尾段有较长的散烟与黑场，原片剪辑未提供同场地、同倍速边界，不能由此推算毫秒误差。
