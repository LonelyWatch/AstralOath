# Windows 战场全屏清晰度

## 全屏时实际绘制多少像素

在 3840×2160、Windows 缩放 150% 的显示器上，用单独产品名的 Windows 诊断程序加载项目的战斗场景。通过 `DesktopDisplayMode.Toggle()` 切换，与主页全屏按钮、F11 走同一段代码。独立桌面中的 Win32 程序记录物理客户区，Unity 逐次保存最终帧，并记录 `Screen`、`Display.renderingWidth/Height` 和主相机 `scaledPixelWidth/Height`。

初始窗口各处均为 1280×720。用 Win32 调整原生窗口后，各处均为 1600×900。切换无边框全屏后均为 3840×2160。切回窗口后均恢复 1600×900。测试使用 D3D11、RTX 5080 和 Ultra 质量档，窗体 DPI 为 144。场景相机直接输出至窗口，URP 渲染比例为 1。短时技能后处理按当前相机像素建立纹理。原始尺寸日志和截图在 `.artifacts/summon-result-r23/clarity/original/`。这是原生 Windows 的同场景诊断包测量，签名热更加载由发布验收另行检查。

## 角色底图和光效的精度

用户提供的日语大招合集文件实际编码为 3840×2160、60 fps、H.264。21:04.75–21:09.00 可见通常形态亚敏的战斗模型、全屏演出和金色技能光。录像的发布时间、游戏内部渲染分辨率、可见倍速和剪辑处理方式均未确认。工程原包亚敏的 `model/arming.atlas` 整页为 490×1513，里面一块脸部底纹 `face_base` 为 41×51。4K 像素数适用于整帧，每块骨骼贴图能提供的独立细节取决于自己的图块。在同一 Windows 测量中，1600×900 窗口的亚敏模型投影约 160×189，4K 全屏时约 385×454，同一组纹理需覆盖 2.4 倍的边长。

逐张核查 2,364 张角色模块模型、立绘、技能及粒子 PNG，Windows 导入均保留原尺寸、关闭 mipmap，并使用 RGBA32。拉斯模型原图为 1476×396，运行时同尺寸。原片与源尺寸核查在 `.artifacts/summon-result-r23/clarity/`。

只读清单共 91,428 项。按当前导入的图集名交叉检索，71 个战斗模型、70 个立绘、795 个特效及 50 个粒子图集名在留存包中均未发现第二份同名 SCT。432 份 CUT WebP 均位于 `cut/fhd`；抽查普通形态拉斯、席可、亚敏的三技能，三份原生切入实际都是 1280×723。角色和剑光原图集指定 `Linear,Linear`，Unity 导入使用双线性取样。源包范围、匹配规则和结果在 `.artifacts/summon-result-r23/clarity/source-variants.txt`。4K 录像展示的是最终合成画面，可见的不同图层与镜头大小也影响清晰感，录制设备及后期锐化参数未知。

首屏的两种来源分别核对。[素材来源清单](../../Assets/Game/Bootstrap/EntryAssetSources.json)记录了节庆标题原生 1600×1180 WebP，以及启动包圣域标题的 CFX、Spine 动作和各层图集。节庆标题生成的 JPEG 保留 1600×1180。圣域标题按 3400 场景单位横向取景，将各层合成为 2048×942 的固定帧。只读包中这些标题图集的单页长边最多 2048，未定位到同构图的 4K 成品。首屏两张 JPEG 的现有平台压缩与这次已经 GPU 复测的战场反馈纹理应分别评估。

战斗通用反馈另有 22 张纹理。其导入器原先只设置默认“不压缩”，Standalone 平台的覆盖配置仍允许 DXT5。对 Windows GPU 做原尺寸读回并和相同渲染路径的 PNG 参照比较，8 张出现大于 1/255 的通道偏差。治疗十字有 32,000 / 65,536 个纹素受影响，峰值偏差为 35/255，速度增益图集峰值为 105/255。其余受影响的图为光晕、闪光、粒子和不死增益。

通用反馈纹理现显式采用 Windows RGBA32，保留 PMA 的颜色及覆盖率。22 张逐像素复查均在 1/255 的容差内，整组 EditMode 为 10/10。原包 GPU 红例与修复后报告分别为 `.artifacts/summon-result-r23/repro/clarity-source-red.xml`、`clarity-source-green.xml`。变动位于资源导入与签名战斗内容。采用这批纹理后，三项图形回归通过，前排不透明区域的治疗残差为 47 / 22,634。报告为 `.artifacts/summon-result-r23/repro/clarity-heal-final.xml`。
