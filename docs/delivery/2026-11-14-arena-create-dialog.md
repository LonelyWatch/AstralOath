# 创建房间弹窗与通用按钮复核

对照用户提供的国服截图和本地 `wnd/pvplive_lounge_creat.csb`。创建房间弹窗沿用原版底板和双层遮罩，按原版宽高比约束在安全区内。Unity 线性色彩空间下，旧版上半部背后的目录文字偏亮。导入工具只把底板的原玻璃填充透明度在上段从 230 提到 245，渐回到原下段的 230，并保留原色和装饰边。派生图片、原文件哈希和九宫格切边见 Arena 来源清单。

点击弹窗外的空白使用普通按钮音效，返回动作使用已有返回音。关闭提示使用实机截图中的灰色叉号和灰色文案，作为整体居中。不勾选「设定密码」时说明、分隔和输入区统一灰显，禁止聚焦与点击。取消勾选时清空原输入。开启后恢复输入。聊天选择使用原版黑色普通按钮和对应的绿色 `#3D7708`／红色 `#A21B1B` 选中图层，未选文字降亮，按压复用原版按下贴图。

Common 确认和取消预制体采用原版绿、棕底图，默认由 260×64 调为 288×91.5，对应原 CSB 在 1280×720 参考尺寸的 192×61。正常图与按下图同样按原版切 9 宫格。使用原版 Daum 字体由 TMP 粗体近似实机白色细描边，调至 31.5 并略上移。创建房间按弹窗尺寸放置两个实例，同时使用同一预制体字重和切边。

本轮改动涉及 Arena 热更程序集与资源，以及 Common Prefab／纹理导入数据。发布时共享资源需要与消费它的包一起更新。本地验证使用重新构建的开发包。

## 验证

- 修改前，Unity 回归用例复现「不允许」显示绿色，Common 预制体两个基准尺寸用例失败。
- Unity EditMode 覆盖共用按钮尺寸、切边、字重及两种音效资源，以及选择框和头像预制体，共 6 项。Unity PlayMode 共 7 项，覆盖密码开关与清空、聊天选择、普通关闭声配置、点击外部关闭、重新打开和两端房间流程。
- 对照 Unity 图形截图的 1920×900 和 1600×900，确认房间弹窗外框比例、上下分层及颜色。手机实机未测。
- 来源导入覆盖 78 个 Arena 和 27 个 Home 资源。验证证据在 D 盘项目的 `.artifacts/arena-create-fidelity`。
