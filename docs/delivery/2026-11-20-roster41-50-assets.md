## 保留重复的 Spine 2.1 时间轨

丽迪卡立绘 portrait/c1046.scsp 的 animation/slots/l10/color 先写入四个键（0、0.7333、4.5、5.3333 秒，从透明到不透明再淡出），随后同一插槽在 0 秒再次写入全透明。洛曼 S2 的 effect/roman_sk2eff_b.scsp 则在骨骼 eff_adlight2 上重复了同一对缩放键和贝塞尔曲线。源文档只按属性名建字典会覆盖前一条轨，旧审计因此中止转换。第二次写入在混合权重小于 1 时仍影响结果。

普通 JSON 保留第一条属性轨，后续轨以 astralOathSlotColorTracks 或 astralOathScaleTracks 按原顺序保存。2.1 读取器使用原生 ColorTimeline 或 ScaleTimeline 逐条追加到同一角色动画。仅出现该情况的资源使用转换器版本 astraloath-scsp/5。转码复核每条附加轨的时间、颜色或缩放值及曲线。

二进制构造样本、真实源文件和真实 Spine 2.1 运行时分别核验转换和播放。色轨在完整权重时落为透明，0.5 权重时两条先后混合得到 alpha=0.5。初始缩放 1、目标为 2 的两条等值轨以 0.5 权重先后叠加得到 1.75。AstralOath.Client.Skeletons 属于母包骨骼运行时；现存母包必须已经具备这两种轨的读取能力，才能通过单发内容更新完整表现这两个资源。此轮为编辑器和独立 .NET 运行时验证。

## 肯恩 S3 的后处理

肯恩 `c_ken_skill_03` 的 ANI #3 经 3732 毫秒延迟触发 #17，再同刻触发题字 CFX #18。#18 的 825 毫秒延迟启动 PPEFFECT #26，`program=sprite_invert`、`duration=1000`，作用期为 4.557–5.557 秒。原作两版 `system/program/sprite_invert.frag`、`system/program_v4/sprite_invert.frag` 均保留 alpha，逐通道计算 `1-rgb`。`u_GrayRatio` 只有声明。本工程使用 Linear 色彩空间，实验室将 RGB 转到显示色域后反转，再转回线性。实验室的实验表现开关控制角色相机后处理，严格模式保留作用范围诊断。

隔离 Unity D3D11 的两条像素回归在旧代码失败。反色时旧红通道 0.604，期望 0.033；模糊先结束而反色仍在时，白色边缘保留为 1，期望 0。修正后相关 EditMode 7/7，包含实际 #26、#69、#82 的色域、alpha=0.37、模糊边缘、节点时长、按 id 停止及整段复位。结果为 `.artifacts/roster-41-50/invert-red.xml` 和 `invert-green.xml`。

角色实验室 PlayMode 通过正式技能按钮选取普通肯恩 S3，打开实验表现，按 60 Hz 从头播放。前 3 秒确有方向模糊，反色保持关闭。对同一张 640×360 相机输入分别保留正常材质及仅取消反色的对照。4.5 秒与 5.6 秒两图全部像素相同；5.0 秒白字紫电变为黑字青绿色电光，三通道相对于 `255-byte` 的整图最大误差均仅 1 个灰阶，alpha 全图逐点相同。图中题字仍有较强的方向拖影，整片相机背景也被反转。此证据验证实验室的触发时段与变色公式，原作的分层作用范围及 SINE_VALUE 对模糊范围的调制仍待核对。D3D11 结果 1/1，`.artifacts/roster-41-50/ken-play.xml`、`ken-lab-frames/`、`ken-lab-s3-invert.jpg`。
