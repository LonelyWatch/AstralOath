## 固定包与回放入口

塔玛林尔 S3 的普通骨架 `skill3` 与立绘完成后场上应使用的身体来自不同源。节点 #6 的完成边分别连到 #11 CUTIN 与 #19 MODEL_BODY，后者明确写有 `model_id=tamarinne_t`。偶像有自己的 S1、S2 骨骼动作和模型时间轴。露娜 S1 的三档、克劳乌燃魂 S3 均有独立演出图；露娜 S2 的固定被动没有对应 STG。

- **塔玛林尔。** 回归在旧播放器中等到 MODEL_BODY 的源毫秒后仍读到原骨架。修复后，S3 #5 的两层 Spine 同时起算，较长者为 1.6666 秒；#6 时长 0.5 秒，#11 立绘在源 2.1666 秒停表，随后同一源秒的 #19 更换场上身体。变身保持当前槽、朝向和时钟。两张偶像图也已将默认模型时间轴改为 `tamarinne_t.timeline`。真实回合夹具从实际开场冷却用 S1/S2 推进，提交 S3 后确认偶像身体与 `sk_c1067_4／5`，再用普通快照重接并观察普通骨架恢复。`battle-edit-form-red.xml` 与 `c1067-idol-turn.png` 可复验。
- **露娜。** S1 三档分别有 3、5、10 个 HIT，同一次权威选档决定回放图。S3 #6 的前后两层云皆用源比例 1.03，STG 给 `y=20` 且未指定角色锚点。旧代码把天空放到受击者脚下，在源 2.0 秒形成右移的局部矩形。原片 25:14.563–14.830 的同一云景连续铺至边缘。该源云景改用画面中心和源偏移，保持骨骼动画、前后层深度和宽屏覆盖；原片静止阶段无法分辨原引擎的锚点，云纹地平线的绝对高度仍有差异。修复前的 960×540 左缘采样蓝色为零，修后左右阵营各在 960×540、1260×540 验证两边三个高度。前云另按 CFX 原语在 1800 ms 开始、100 ms 内从 1 降到 0。参考与修复前图在 `references/c1066-sky-comparison.jpg`、`references/c1066-sky-before.png`；实际朝向对照见 `battle-frames/source-playback/c1066-sky-*.png`。
- **克劳乌与卡威利。** 旧版仅接受有名字且无限期的 66 号目标透明层，导致这两人的匿名有限层从不生效。克劳乌普通／燃魂 S3 #34 持续 3500 ms、淡入 200 ms；卡威利 S3 #26 持续 2166 ms、淡入及淡出各 160 ms。保留身体原先的暗化与同一战斗其他表现层的所有权，逐受术者淡至零并按源时长恢复。修前两例在淡入中点都没有写入 0.5，见 `battle-edit-finite-red.xml`。克劳乌两张图各播出三段不同立绘，分别采集骑士、战马和正面特写。
- **修尼尔、维尔萝娜和菲奥雷托。** 修尼尔 S2 #9 的 32 号位置在这条明确的地面环上按在场己方的地面中心生成一套。S2 的最终实帧可见四人共用金环。维尔萝娜按 S3、S2、S1 的正常指令积累专注后出现追加 S3；菲奥雷托受击回避后反击 S1，分别检查真实队列中的起因、图号和实际播放器。两个回合样图在 `c1071-real-extra.png`、`c1074-real-counter.png`。

共 565 张 PNG，其中 422 张为可直接查看的合成帧，其余为模糊前世界画面及角色隔离帧。另有 34 份相机坐标/倍率轨迹。已查看每人的真实阵容、代表 S1/S2、S3 半秒阶段表、立绘及收尾，以及三档攻击、变身、燃魂和实际回合分支。178 个反馈时点包含无 HIT 图用于 HUD 同步的回放反馈，不能将它们合计为原游戏造成的伤害段数。曝光、粒子随机、多次命中表现、场地和原片伤害 UI 没有做逐像素等同验收。

最终 `battle-play-accepted.xml` 六项全部通过，包括十人完整源图、两个真实回合外行动、塔玛林尔真实变身、露娜双侧宽屏与既有睡眠／眩晕。最终 `battle-edit-accepted.xml` 的 56 项全部通过，覆盖模型切换、镜头、时轴、CFX 动作与有限目标透明层。实战日志中修尼尔 S2 #9、露娜 S3 天空锚点和 Opacity、克劳乌 S3 #34、卡威利 S3 #26 的旧诊断均已消失；其余未确认指令仍可在同份日志复核。
