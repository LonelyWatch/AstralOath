# Windows x64 本机试玩包 0.1.23 / R23

## 更新和多开

使用 0.1.23 的玩家沿用现有母包，下载更新后按提示退出并重新打开。独立试玩包完整解压后，双击根目录的 `AstralOath-Play.exe`，每次启动一个窗口。游戏服务地址为 `localhost:7728`，本机签名内容源为 `127.0.0.1:5295`。当前最低客户端版本为 0.1.23。

## 构建与签名

从 `88125206f9146a0772f32c7f556d8f5bd1a690cc` 核对 23,272 份 Git/LFS 输入。Windows 热更构建使用 R22 的 IL2CPP 母包归档 `25cda4dbafde4770b98611b1323689a1`。最初构建发现治疗特效引用旧 AOT 裁剪掉的 SortingGroup 属性。改用该母包已有的 Renderer 排序接口，以及随业务预制体和场景分发的材质后，HybridCLR 检查通过。

YooAsset 报告确认包含行动者脚底光圈、四名英雄新增的切入描述和帧、黑幕混色着色器以及战斗场景依赖。签名清单共 98 个文件，2,225,010,324 字节。与 R22 同路径同哈希的 81 项可以复用，17 项需要下载，共 219,873,544 字节。清单 SHA-256 为 `2f810625372a9301de1f3ac77cd675ef1ead42e467a19c3232c10390ff34e5bc`。从交付播放器的资源中读取原公钥，对落盘内容执行协议 1、结构 3 的独立验签通过。

## 本机验证

- 切换前确认模拟战房间为空，切换后按原测试会话读回相同的三名英雄实例。7728 已由 R23 配套服务监听，5295 返回签名版本 23。战斗规则 17 和配表哈希不变，服务端构建记录复核了 17 个发布文件。
- 实际 Windows IL2CPP 进程激活 R23 并从游戏服得到回显 9。从包根目录的多开 EXE 连续启动两个无窗口进程，两者分别报告 `ASTRAL_CONTENT_ACTIVE version=23 recovered=False`，独立获得回显 11 和 10。
- 下载确认、取消和更新完成后等待用户确认重启的 Unity 入口回归 2/2 通过。上述自动回显使用非交互启动模式。验证记录在 `.artifacts/ui-r23/qa` 及 `.artifacts/summon-result-r23/root/r23-update-screen.xml`。
- 交付 ZIP 共 1,170 个文件，2,091,231,020 字节，SHA-256 为 `8cab76011d1a8ca7fa63fdb28da09cda88db8c1a52985d500b8954b7b5a1905b`。在含空格和中文的路径实际解压，每份文件的解压流、落盘文件与发布目录哈希一致。解压目录的签名再次通过验证。
- 从解压目录的原生图形客户端进入本机双席位模拟战。双方选人预览同步，客户端报告 8 人入场、权威倒计时生效、本方座位为房主，且成功消费服务端第一个有效命令，正常退出。日志在 `.artifacts/r23-package-battle-57bd4fba17d44133abe86cbee24d704a.log`。
