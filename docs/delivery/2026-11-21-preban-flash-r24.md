# 预禁头像白芯的范围与消退

用户所示为最近选择列表中的单格预禁落章。《2026 秋季赛纯核面板分享》P2 本地文件编号 43325065328，1920×1080、30 fps。04:04.6 和 04:05.0 前后可以连续看到两次点击，第一次的局部白芯中有重复视频帧。第二次的连续帧用于测量消退。视频发布日期和游戏内倍速未确认。点击中心还有独立的蓝紫色触摸提示。

原包 `ui_pre_banned.cfx` 有三条粒子轨，实际运行五个发射器。该组配置均指定 `blendFuncSource=770, blendFuncDestination=1`，即 `SrcAlpha, One`。R23 用 `One, One` 叠加粒子，低透明度边缘的贡献过大。修正这一组材质的源混合因子后，动画仍使用相同的图集、骨骼缩放、时钟与粒子轨，主列表和最近选择共用实现。

逐帧读取 UI 合成画面，以头像金框直径归一化。点击后 0.20 秒，穿过圆心的连续白色部分在原片为 1.12 个头像直径，R23 为 1.50，修复后为 0.97。到 0.233 秒，原片和修复后的中央红斜杠均已分开白芯，R23 仍有连续 1.45 个直径的白芯。0.267 秒时 R23 在主列表自选头像和邻位新增的近白像素分别占 72% 和 20%，修复后是 18% 和 7%。原片的初始两帧本身有强白闪；上述比例按后段逐帧测得，各次粒子及英雄底图有差异。

实景测试分别点击主列表和最近选择，采样同一英雄在两处的最终颜色，覆盖初闪、中段、收束、稳态，以及原有排序和撤选。R23 新增回归 0/2，修复后相关回归 3/3。参考、R23、修复后三排对照在 `.artifacts/r24-preban/qa/srcalpha-comparison.jpg`，报告在同目录 `r23.xml`、`srcalpha-suite.xml`。
