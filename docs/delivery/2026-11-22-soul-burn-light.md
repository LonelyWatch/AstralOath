# RTA 烧魂头像的入场光束

## 画面对照

用户截图 `codex-clipboard-9f9b4380-bb33-4d89-9d1b-2e826ce62a3a.png` 中，左上头像照出的两束光在战场中央露出了平直的端部。核对用户提供的《2026 秋季赛纯核面板分享》P2（`2.3060-3091_43325065328.mp4`），13:40.933–13:41.367 的对方头像入场，以及 13:44.5 的持续火环。画面为 1920×1080、30 帧每秒。发布日期、录像中的游戏倍速未核实。这里比对的是 RTA 玩家头像的烧魂提示，两个角色阵容不同。

取 13:41.167 斜束已展开、细白环清晰的一帧，与 Unity 0.25 秒同姿态对照。以右上头像为中心，在朝左下的 108°–166° 范围按角度取样。用内外各 22 像素的相邻亮度作背景，跨角度取中位数定位环心线。原片半径 939 像素，旧项目 489 像素，修复后 936 像素。取样方向以屏幕向右为 0°，向下为 90°。这三个数来自截图本身。逐帧原片位于 `.artifacts/soul-burn-light-r32/original-onset.jpg`，三图对照位于 `.artifacts/soul-burn-light-r32/comparison.jpg`。

## 原因与修复

`BattleOnlineHud` 创建 `ui_livepvp_soulburn_eff.cfx` 时，入场使用了 0.36 的像素比例，原生光束网格和同步扩张的光环一起缩短。光束仍处于高亮时，可见其几何端点。将入场比例调到 0.69。头像左右沿用同一个校准值。原生 Spine 的时间、网格、UV、混合和动画期间的视口均沿用已有实现。入场光退去后过渡到 0.50 的持续火环比例。13:44.5 的原片样本中火焰宽约 260 像素，头像宽约 130 像素。

## 验证

- 在独立 Windows 镜像运行 Unity 2022.3.62f3 D3D11 的 `BattleActionFeedbackVisualTests.NativeActionFlashesAndBothSoulBurnAvatarsRenderAndClear`。增加渲染网格的光环半径断言后，旧代码实际为 489.35，低于录像容许区间 815–1100。更新比例后通过。用光环度量可以复核伸出摄像机的光束，即使屏幕里已看不到端点。
- 左右头像均验证起始、0.25 秒入场、持续光环、停止发射后的粒子尾迹及释放。原始测试结果和 1920×1080 截图位于 `.artifacts/soul-burn-light-r32/red`、`.artifacts/soul-burn-light-r32/green`。这项图形验证使用战斗场景和事件夹具。不同背景下的最终亮度、多种宽高比的同构图尚未逐一测量。
