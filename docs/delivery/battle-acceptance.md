# 后续战斗场景验收

本清单由用户监督执行。基础设施通过不能推导出资源齐全或战斗完全还原；需要逐项提供原作证据、资源映射、运行录像与可重放的输入输出。

1. 先选择一组双方阵容和固定配置版本，补齐角色立绘、骨骼/动画、贴图/图集、技能特效、镜头、音效和日语语音依赖；任何缺失应记录具体资源 ID，不用占位图算作通过。
2. 用最小实际战斗场景验证站位、回合顺序、速度与行动条、选取目标、普通技能/大招的完整时间线、跳过/加速、暂停与恢复。UI 动画不得决定权威结算。
3. 针对命中、暴击、属性关系、伤害、增减益、护盾、反击、追加攻击、死亡/复活、被动触发和优先级建立带证据的规则用例；固定随机源种子，比较客户端演示与服务端事件序列及快照。
4. 单独还原 BP 阶段、队伍/英雄限制、先后手、禁用与选择顺序、超时、确认、断线与重连、配置赛季差异。协议契约或空状态机不能代替实际 BP 验收。
5. 在 Windows 与 Android ARM64 真机验证文字、中文缺字、日语配音、Safe Area、超宽屏、平板、不同 DPI、暂停/切后台、网络中断和更新恢复。测量帧时间、内存、包体和加载时间。
6. 对真实战斗权威服务进行 2 核 4GB 环境压测；确认每房间 CPU、内存、数据库读写、网络与并发上限后再确定百人容量，资源/数据库备份需做目标机恢复演练。

每个验收项记录：版本、证据位置、实现模块、源资源及哈希、测试步骤、实际结果、差异与用户结论。国际服规则变化只在用户提出追踪时更新证据。
