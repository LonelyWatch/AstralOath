# Windows 战斗与英雄背包试玩 R32

R32 的启动入口是主工作区下的 `.artifacts/windows-r32/Play-R32.exe`。本版本修改了 Common AOT 的按钮与声音路由，使用新母包 0.1.25 和对应签名内容。R32 训练服地址为 `127.0.0.4:7728`，签名源为 `127.0.0.1:5303`。构建镜像的 23,533 项受版本控制输入来自 `f9dfed6e`。

## 实机复查入口

- 在英雄页和竞技场选人页，拖动右侧卡条经过数名英雄，再让卡条靠惯性停住。两处跨卡播放同一个原版短音。打开背包、打开或收起快捷菜单、选择物品和返回页面可听到各自的反馈。[录屏时间与音轨](2026-11-22-inventory-audio.md) · [滑动音依据](../development/roster-scroll-audio.md)
- 在英雄页进入装备槽或神器，比较确认按钮声和成功配戴声。取消时只有操作按钮自身的反馈。戒指与神器有原录像对照。武器、头盔、护甲、项链和鞋按五个独立的原库事件配音。
- 在模拟战，从双方视角检查凯隆 S3 抓取和全屏切入，泰妮布里雅 S3 双月之间的目标。伊赛丽亚、凯隆和济纽亚的动作结束与画面残光分开；迪埃妮和尤娜的白幕渐退到战场。[镜头与目标](2026-11-22-stage-contact.md) · [217 张图的收尾](2026-11-22-battle-action-recovery.md)
- 对同一目标先打多段伤害、再触发其他攻击，第一次攻击的损血段会在自己的最后一击后收缩。冷却技能可长按查看说明，短按无法选中；主动技能以外的触发技能出现连锁闪光。[血条逐帧复核](2026-11-22-multihit-health.md) · [烧魂光束](2026-11-22-soul-burn-light.md)

## 本机发行与验证

Win64 IL2CPP 母包基线为 `e009595d3a8a4186a1ffaad76323e806`。从成品提取的公钥通过了签名及清单文件校验，清单 SHA-256 为 `7216f5f5e55264d4e5b6589696f7c2ec7c82c766a18d68e468787fc587119219`。98 项业务文件共 2,238,374,796 字节。成品场景资源中核对了 18 个 Canvas 音效。

空业务缓存首次启动实测下载 2,238,374,796 字节。退出后重开新增下载为 0 字节，两次均运行于 D3D11、激活 R32，并正常退出。进入背包与英雄单槽页读取七件普通装备，头盔描述一致。拉斯的生命值从 263 到配戴后的 343，卸下后恢复为 263。回执 `first-activation.json`、`cached-reopen.json` 和 `transfer-receipt.json` 位于启动器同一目录。

停止 R32 两个服务后从 `Play-R32.exe` 启动，恢复游戏服务和签名源，并同时打开两个 D3D11 客户端。原 MySQL 进程在这次实测中持续运行。回执为 `cold-launch.json` 与 `multi-launch.json`。启动器 SHA-256 为 `8e3edeff22a2ea83847bc758f6d968b6ae74839570ecb771e9f2501db4228164`。

两个原生客户端完成建房、入房、成员更新、双向聊天和离开，主客双方均以 0 退出。另测选禁、八人入场、倒计时及执行服务端第一条技能指令，见 `native-arena.json`。早先用户遇到的偶发套接字报错未在该次联机中重现，取消与重连错误路径另有可控的 Unity 回归。

原生召唤测试完成十连，得到十张结果卡。在五种窗口尺寸上均读取到有效渲染纹理，退出码为 0。回执为 `summon/2443e19b956f49b2bab8985033f39b6d/verified.json`。
