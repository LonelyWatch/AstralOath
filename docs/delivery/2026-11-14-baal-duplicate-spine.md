# 巴尔＆塞尚的重复 Spine 位移轨

普通巴尔＆塞尚 `c1015` 的三份 SCSP 2.1.27 文件包含同一动画、同一骨骼的多条 type2 位移轨。转换器原先会拒绝重复轨道。其引用的参考解析器还会用后来的轨道覆盖前面的整条轨道，丢掉 S2 特效在叠加轨首帧之前的位移。

## 本地源证据

下列路径相对于只读解包目录 `D:/sevenepic/原始资源`，偏移是解压后的骨骼二进制偏移，时间单位为秒。

- `effect/baalcezanne_skill2_b.scsp`，SHA-256 `43f4804602300ea313701281b15d681524d988894b31bc433d0802c0a651190c`，完整消费 35,501 字节。骨骼 #0 `root` 的第一条轨位于 18584–18701，8 帧覆盖 0–2.9333，1.2666 时 Y 为 -15.39，2.9333 回到 0。第二条轨位于 19832–19858，仅有 1.2666 时的 Y=-15.39。
- `effect/baalcezanne_skill2_f.scsp`，SHA-256 `37eb0cb646e0d695b513445e935f79657569e06551aabd3d4097f4aeb576f159`，完整消费 136,394 字节。骨骼 #0 `root` 的轨道位于 76627–76718 和 87449–87475，第二条同样只有 1.2666 时的 Y=-15.39。另有骨骼 #44 `bone` 的两条轨道，分别位于 76931–77009 和 87573–87611，均覆盖 0–2.9333。0.0333 秒第一条的 Y 为 2.03，后条仍为 307.94。
- `camera/BaalCezanne_skill3_cm.scsp`，SHA-256 `70cc6fef82838c24946b0d1b8c35fe779e230dcdbfb9f92299ccb8f153e43b52`，完整消费 1,166 字节。骨骼 #0 `root` 的两条轨位于 1114–1140 与 1140–1166，均为 3.8 秒的 (0, 0) 单帧，两个二进制记录完全相同。第三条位移轨针对其他骨骼。

独立只读检查了 [梅赛德丝曲线核验](2026-11-12-mercedes-curve-correctness.md) 中同一 SHA-256 的本机原版程序。type2 读取入口 `0x140739415` 为每条轨单独分配记录并保存骨骼索引和帧数组。公用写入段 `0x140739E11–0x140739E59` 按序号写入动画轨道数组，随后递增源轨道计数，未按骨骼或关键帧时间去重。type2 求值入口 `0x140E83DB0` 在首帧前返回，末帧后持续使用末值，并按 `当前值 + (绑定姿势 + 轨道值 - 当前值) × 权重` 修改当前骨骼。固定的 Spine 2.1 核心以相同顺序应用位移轨。 [Spine 2.1 Animation.cs](https://github.com/EsotericSoftware/spine-runtimes/blob/142e770e5b4b42395a3a0a68ff3c8a21ba2774eb/spine-csharp/src/Animation.cs)

## 转换与播放规则

标准 `bones/<bone>/translate` 保留第一条，动画的 `astralOathTranslateTracks` 按骨骼和源顺序保存余下的独立帧数组。转换时校验索引、帧数、单调时间、有限坐标和曲线映射。每条位移轨的时间、坐标和曲线独立对照源记录。其他轨道的重复输入继续报错。

AOT 层为每条额外记录创建独立的原版 `TranslateTimeline`，在同一骨骼的普通位移轨之后按源顺序应用。所有轨道获得同一个混合权重。补足绑定姿势的混合逻辑用该骨骼最早的位移键判断是否已开始。仅含扩展字段的转换产物标记 `astraloath-scsp/4`。部署这类资源时，母包须先包含扩展读取能力。

## 验证

- Python 合成 SCSP 复现重复轨拒绝，修复后通过。覆盖相同轨道保留、轨道顺序、帧时刻、坐标和曲线、损坏轨道拒绝，以及普通 SCSP 省略扩展字段。
- .NET 骨骼冒烟回归使用相同的 AOT 读取代码和固定 Spine 核心，修复前 1 秒满权重 Y 实测 +3、期望 -1，修复后满权重与半权重的所有取样通过。
- 三份实际骨骼完整转换并通过 297 个 30 FPS 采样。S2 后景在 0.6333 秒为 -7.695，2.9333 秒满权重为 -15.39、半权重为 -7.695。前景骨骼 `bone` 在 0.0333 秒满权重为 307.94、半权重为 154.4775。S3 镜头根骨骼从 Y=16 开始，半权重下 3.799 秒仍为 16，3.8 秒两条轨顺序作用后为 4。
- 逐一对照 222 份已有骨骼，生成 JSON 字节和诊断对象与原转换器一致。真实源样本和临时清单位于 `.artifacts/baal-ordered-spine`。
- Unity EditMode 骨骼曲线专项 6/6，含 `OrderedTranslateTracksKeepTheEarliestKeyDuringACrossfade` 的真实播放器混合及定位检查。原版完整技能录屏逐帧对照与普通形态角色接入仍待独立验收。
