# S3 目标及信息条可见性调查（2026-11-13）

## 复现路径与根因

本轮针对拉斯S3后半段出现敌方血条和浮字、但没有人物本体的问题。当前 `BattleCinematicStage.ApplyLayout` 将 away_x绝对值>=1280 的布局映射为关闭所有非施法者Renderer；这只是为保持作者站位的项目近似，并非完整执行原布局搬移。在末尾mode=1之前没有解除目标临时隐藏；源镜头切到敌方群中心时只能拍到被关闭的目标。

只读核对当前导入原图 `c1001/Configs/stagept/c_ras_skill_03.graph.json`：

- 起手 `LAYOUT #5`：away_x=5000，fade/time均200ms；`CAM #6/#8`聚焦施法者。
- `ANI #10` 开始后1848ms触发 `CUTIN #19`；其完成后 `CAM #26` location42/x=-300/y=200，随后 `CAM #16` location42/y=-50/time200ms。
- 目标镜头完成再延迟200ms启动爆炸 `EFFECT #20`。其开始后132、363、1122、1287、1452ms有五个HIT。
- 五段HIT之前没有新的LAYOUT，唯一 `LAYOUT #22 mode=1` 在爆炸CFX完成后200ms。等待mode=1才解除目标隐藏会直接覆盖全部命中阶段。
- 按现有时钟契约计算，CAM42在源1.848秒，爆炸2.248秒，HIT为2.380、2.611、3.370、3.535、3.700秒；CUTIN仅增加墙钟、冻结源时钟。实际播放器时间和截图由协调者复验。

梅赛德丝S3 `LAYOUT #4` 为self_x=.1/away_x=150/fade/time200ms；它在当前策略里仅隐藏不参与的旁观者，接受的敌方全体目标一直保持可见。两个角色不能统一套“所有非施法者都隐藏到整段结束”。

## 目标契约

保留开场施法者近景的临时目标遮蔽。在明确聚焦目标的CAM位置5/12/16/31/32/41/42开始时，解除**该次布局拥有的目标遮蔽**，恢复各目标的原Renderer.enabled，包括其槽位地面影子；旁观者依旧保持遮蔽，直到源mode=1、下一动作、取消或释放。不得把原本关闭的Renderer强开，不操作权威实体/槽位活性，不对角色ID写特判。

信息条由场景View在演出推进后读取当前身体Renderer的显示状态，人物被该布局隐藏时，自己的血条/等级/状态同步隐藏；没有隐藏的人物保留自己的信息条。全屏CUTIN仍由幕布自然遮挡，不能恢复“整片HUD一刀切”。该集成及真实Scene回归由协调者负责。

## 证据边界与回归

LAYOUT self_x/away_x实际空间搬移和fade曲线仍未完整还原，本次是使已有临时遮蔽策略正确响应源导演焦点，不宣称完成原布局引擎。新 `BattleLayoutTargetVisibilityTests` 使用当前拉斯/梅赛德丝原图节点、四目标与旁观者，覆盖目标镜头、原本隐藏目标、重复布局、影子和取消恢复；先由协调者运行失败回归再实现。真实九技能播放器还需逐个HIT检查目标身体、并采集S3命中帧，不能再以单张速度线截图替代。

协调者已实际执行 `.artifacts/layout-target-red.xml`：10项中9失败、1通过，Ras目标镜头后四个目标仍关闭；梅赛德丝有限布局保持目标的原行为通过。随后生产仅在CAM聚焦目标时按当前mask所有权恢复原Renderer状态，旁观者mask保留。绿色结果与真实HIT帧由协调者填写最终交付。

最终协调验收：该组10项在完整431项EditMode中全部通过；真实九技能两朝向逐HIT检查通过，另有真实View显隐/死亡/重开与渲染后挂点检查。正常CFX亮白会遮挡部分目标，去CFX同帧诊断确认四体在画面内，不能把Renderer启用推断为原作层序已完整还原。最终记录见[本轮交付](2026-11-13-camera-visibility-fixes.md)。
