# 模拟战 BP 与局内画面对照清单

核对基线为 Windows 0.1.18 R2、源码提交 `1f50415c`。画面先裁去窗口标题栏和视频黑边，再按 16:9 游戏视口对齐。开发截图与 Windows 实包截图分别记录。不同英雄的姿势、武器、披风和特效会改变外框，角色大小以同角色同姿势的头到脚高度比较。

本次使用用户提供的完整 P2 本地录像（34:20.83、1920×1080、30 fps）逐帧复核。下列时间以这份录像为准。

## 修改清单

- [x] **01 角色比例。** 本方 0.1.18 对局中主体偏小。实战模型绕脚点放大，角色依画面容纳空间最高增加约 17%。地面透视、脚点、血条锚定和命中区分别核对。以 16:9 为主，同时看近、远站位和大型英雄边缘，复测超宽屏及选位预览。
- [x] **02 默认技能与亮光。** 开放我方操作时默认可用 S1 已选中并播放原包选择闪光。当前有 S1 逻辑索引，联机等待就绪后没有重挂选择框。测试进场、换人、重连、切换 S2/S3、魂燃和只允许其他技能的场景。
- [x] **03 左下当前英雄血条。** 现有 `game_hud_bar_hp` 是 2×6 头顶色条，直接拉伸后成为直角纯色条。按原版当前英雄条重建斜切端和有高光的绿渐变。比较满、半、低、零血，满血和部分血右端仍要有斜边。
- [x] **04 左下当前英雄 HP 数字。** 保留斜杠和并排数字，按原版核对字高、字重、间距、颜色和数字与血条基线。原版 `inbattle_order.csb` 仅提供 `n_unit` 挂点，数字的具体字体绑定暂未确认。
- [x] **05 当前英雄 HUD 交接。** 原版连续帧显示旧立绘稍向右淡出，新立绘从左侧进入。两者短暂重叠，约 0.2 秒完成。名称、数值、属性和职业与立绘属于同一切换组。换英雄才重播，同英雄更新生命不重播，快速切换结束后显示最终角色。
- [x] **06 15 秒局内决策。** 原版操作帧显示 15 秒，当前对局服务端默认 30 秒。将新对局的服务端决定窗口改为 15 秒，已存对局窗口遵循原值。双方完成进场或上一次演出后才开表，计时归零触发一次托管。
- [x] **07 魂燃方玩家头像火。** 当前只有魂燃按钮、技能框和灵魂槽反馈。按权威 `Action.UseSoulBurn` 在施放方顶部头像播放，双方镜像一致，点亮或取消预选都不应假触发。原 `ui_livepvp_soulburn_eff.cfx` 是头像候选，包含约 1 秒入场和 0.333 秒循环。该循环保持到本次行动的连续演出结束，再淡出。
- [x] **08 追加、额外回合、反击、夹攻闪光。** 当前派生行动主要显示文字。按权威事件分别触发一次，沿行动者锚点播放，不延长命中或拖慢接续。原 `stse_chain.cfx` 和 `stse_addturn.cfx` 有源时序可比，`stse_counter.cfx` 已证实用于反击状态附加；反击动作使用 8:05.2 及 8:06.9 无独立蓝拳的链式闪光，额外回合圆环按 8:26.2–8:26.7 校准。独立追加招式的专用素材未从原片确认。
- [x] **09 非法目标压暗。** 技能可操作时，用服务端同源规则计算合法目标。只压暗非法的其他角色模型。施法者保持亮度，地面、UI、血条及状态特效各自正常显示。切技能、取消、敌方回合、技能演出和结束后恢复；镜像、潜行、嘲讽、全体和复活走同一判定。
- [x] **10 等级旁的红色编号。** 合法目标的血条等级左侧显示原样式红色数字标记，实际点击标记也应提交对应角色。编号与左侧行动条上的同一角色一致。换技能或场上合法目标更新时同步，禁止点到失效标记。
- [x] **11 BP 光效与阶段。** 用留存 P2 对照当前预选两侧、锁定白闪和终禁火星。核对亮光边缘遮罩、红蓝色、确认与等待文字、阶段推进时印章和 30 秒阵型。本次改暗空卡槽，按对重播斜切预禁揭晓，阵型阶段切换文案并隐藏预禁底栏。两对各展示 0.83 秒，最后淡出 0.18 秒。印章进入后持续覆盖两对，双色斜切衔接和原始火星贯穿换组。
- [x] **12 局内魂量提示。** 原版先手操作帧可见头像下方蓝色魂标、对手回合指示、头像边饰、表情入口和右侧规则状态。区分录像赛事叠加和真实 HUD。检查实际接入的玩家侧灵魂、计时、技能冷却、目标编号和提示文案，不凭头像推断未传输的段位和公会。
- [ ] **13 演出与实际等待。** 参考 7:33.17–7:37.33 的关门、停留和开门，当前 0.1.18 旧的双开验证曾测得约 6.6 秒关门等待。以本轮实际 Windows 双端日志复测，区分缓存加载、场景安装和演出。保持双端就绪闭环，不能提前开门暴露半加载画面。
