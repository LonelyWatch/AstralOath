## 复现与实现位置

- 录屏采样在 `.artifacts/arena-tower-review/frame-34.jpg`、`frame-206.jpg`、`frame-269.jpg`。用户指定壳图为同目录的 `before-directory.png`。上一版三个实际 Editor 渲染位于 `.artifacts/arena-tower-review/final/`。旧版列表灰块厚重、有截断行及裸头像；备战缺少左右编队资料和单位职业等级牌；历史弹板难以辨别防守、进攻两行。
- 只读源取自 `D:/sevenepic` 的 `pvp_bar`、`mob_icon2`、`pvp_ready`、`pvp_attack_guide` 系列布局；节点坐标输出在 `.artifacts/arena-tower-review/geometry/`。列表原设计为 690×108，行距 128。攻击指南底板为 800×578。Unity 高度 1080 的设计坐标使用原 720 高度的 1.5 倍。
- `Assets/Game/Editor/ArenaUiBuilder.TowerShop.cs` 的关卡生成段和 `ArenaUiBuilder.TowerFormation.cs` 生成关卡页、编队、首通弹板。运行绑定在 `Assets/Game/Modules/Arena/Scripts/ArenaTower.cs` 和 `ArenaTowerBinder.cs`。中文词条在 `Assets/Game/Modules/Arena/Configs/arena-zh-hans.json`。
- 本轮塔新增原始精灵共十张，位于 `Assets/Game/Modules/Arena/Res/Textures/Tower/`。等级牌使用 `battle_pvp_hud_bar_bg.png` 以及 `game_hud_bar_fire/ice/wind/dark/light/none.png` 六款精灵，其余为 `_btn_white.png`、`icon_filter_knight.png` 和 `cm_icon_etcbp.png`。可按 `Tools/Arena/ImportTowerShopArt.py` 重建。等级数字、职业、星、圆框、对阵地板和 VS 复用原有资源。两个页面各自实例化通用 `MailEntry`、`ChatEntry`，账号未读和收发依赖由 Foundation 的 `ShowPageWithMail` 绑定。
- `ArenaTowerPageTests.ScrollsToCurrentStageAndRoutesClearTeamAndOwnedFormationIndependently` 在已过54关时开页，检查55关居中、可见3行、跨关禁用、首通快照和自有英雄选择；输出三个 PNG 及配套节点屏幕坐标 JSON。分别用 `ASTRAL_ARENA_CAPTURE_SIZE=2464x1200`（与有效视频同宽高比）及 `1920x1080`（窗口）渲染。图像与坐标均以同一次相机渲染为准。受控样本的英雄与奖励只用于验证界面。音效和战斗结算未改动。

运行 `python Tools/Arena/CheckTowerLayout.py <截图目录> --output <指标文件.json>` 可检查相机坐标。窗口改变时，居中的固定尺寸保留原高度单位，边栏和阵型锚点随宽高比布局。脚本逐项给出实际值、目标、差值、容差，超出范围返回非零状态。

第一轮宽屏截图中，三个完整行的实测顶端依次是 140.9、247.6、354.3，行高 90.0，首个防守英雄直径 62.8。首通面板实测左上 (282.7,62.2)，尺寸 666.7×481.7。原始截图右半区域采样的非选中行底为 RGB(44,43,39)，第一轮为 (94,94,97)，防守横条分别为 (24,45,62) 和 (48,77,101)。据此降低 Unity 线性颜色空间中两处的混合强度，给首通底板补了保留圆角的深色衬层。搜索恢复行时 GameButton 在禁用期间释放点击绑定的问题也在第一轮操作中暴露，恢复可见时已重绑。

## 最终受控实测

画面文件为 `.artifacts/arena-visual-rework/final/{wide,desktop}/01-tower-stage-55.png`、`02-tower-clear-team.png` 和 `03-tower-formation.png`。两个尺寸各有 `tower-geometry.json` 和 `PlayMode.xml`。逐张查看共六张实际受控截图，两个尺寸各通过 44/44 项几何比较和 5/5 项合并 PlayMode 操作。关卡行高 90、宽575。横条采样最终为 (24,43,60)，原片为 (24,45,62)；关卡背景采用用户指定的模拟战外壳，行底在相同视频坐标处为 (61,61,67)。牌面等级显示两位数字和彩色底板。

备战的 VS 来源图周围带透明边，单测中心对齐后进一步按原布局将精灵画布固定为 207×207 源单位。最终同宽高比图在 600 高游戏画面上的橙黄亮区宽 138，原片同样为 138；阈值范围内的高度分别为 106 和 115。首通只展示该账号第一次胜利的一行记录，底下留空；备战只有实际持有英雄，测试账号带有三名持有英雄。未新增动画、音效和对战回放，回放入口使用共用功能提示。
