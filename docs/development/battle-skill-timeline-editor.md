# 技能演出编辑器

在 Unity 编辑模式打开 **Tools → 战斗场景 → 技能演出编辑器**。左侧按中文名、角色 ID 或演出图 ID 检索，选 S1、S2、S3。技能槽来自角色实验室源图。实际战斗是否能主动施放以及使用哪张图，以 Luban 技能表为准。角色报告列有被动槽及变体的差异。用于提速条件的独立图按权威槽显示，例如席德的「S1 · 提速」。

- **预览**使用独立战斗场景、原骨骼、场景、镜头、特效、Cut-in 和命中反应。换边可以检查镜像，支持选目标角色及单体／全体友军或敌军，也可以按技能规则设置目标，双目标技能使用前位和下位两名敌方。空格播放或暂停，左右方向键逐帧，Home／End 跳首尾。声音开关用于从零点开始的 1 倍速播放，拖动时间线后进入静音诊断。
- **时间线**按动作、镜头、特效、全屏、条件分轨。单击标尺移动播放头，也可直接输入帧号。片段和节点下拉菜单都能定位并查看参数。「下一命中」跳到下一个 HIT。拖动片段修改该节点在源图的绝对起点。节点的下游仍由 STG 连线及事件计算，其他绝对定位节点保持指定起点。支持 24／30／60 fps 吸附、缩放和横向滚动。
- **两个时钟**。面板的播放秒数包含 Cut-in 时钟，源秒数在 Cut-in 播放时停住。节点属性和覆盖始终用源毫秒，跨 Cut-in 拖动按实际播放时点换回源时间。切到较早的帧时从零点重新执行并重建可见状态。
- **编辑**在右侧修改该节点已有的可写镜头、位置、缩放、时长、过渡等字段。可使用 Unity Undo／Redo，或点「还原此节点」。「还原本技能」恢复整张图，保存前可撤销。「对照原图」会在相同时间预览原始效果。选取技能后可点「原始图」定位源文件。保存会写入可版本管理的 `Assets/Game/Modules/BattleScene/Configs/skill-timeline-overrides.json`。只含实际节点改动，导入图和 `D:/sevenepic` 保留。
- **战斗生效**由 BattleScene 的序列化依赖将覆盖表交给同一个播放器。对照图的指纹和节点 GUID；原始图升级后需在编辑器复核并重录失效覆盖。运行时发现不兼容覆盖会报错并播放原图。改动属于表现，不经过技能数值表，也不改变战斗规则版本。对 Player 发布按场景资源及程序集适用的更新入口复验。

同轨道重叠的片段自动排入不同子行，时间轴密集时可上下滚动。标尺使用当前帧率显示帧号，悬停片段可查看播放帧号和源秒数。Shift 滚轮缩放，Alt 滚轮横移。末帧事件可点选。

## 适用边界

编辑器显示 STG 节点及运行时解析的时点和长度，并显示模型 timeline 中的命名事件、效果、镜头震动和播放器诊断。模型 timeline 条目可跳转和查看参数。CFX 内部粒子、Spine 骨骼关键帧与 FMOD 波形不展开为可编辑轨道；现有曲线字符串按源格式编辑。独立预览不会运行战斗规则或生成数值结算。分支和锚点的当前解释，以通用演出规范和十人基线为准。

操作参考了 Timeline 的轨道／片段组织，以及 Sequencer 的标记、帧率、吸附与播放控制。项目复用自身播放器以保留 Cut-in 与源帧事件语义。[Unity Timeline](https://docs.unity3d.com/2022.3/Documentation/Manual/com.unity.timeline.html) · [Unreal Sequencer](https://dev.epicgames.com/documentation/en-us/unreal-engine/sequencer-cinematic-toolbar-in-unreal-engine)

## 验证记录

Unity 2022.3.62f3 全量 EditMode 492 项通过，其中技能时间轴专项 9 项，覆盖拉斯 S2 与梅赛德丝 S3 的真实渲染、Cut-in 双时钟、回退后的镜头及画面、独立场景释放，以及移动拉斯 S2 命中节点后编译轨道和播放器时点同步改变。覆盖测试验证了源图不变和无效节点拒绝。Windows Editor 批处理运行，Player 目标平台构建未执行。后续编辑器专项增至 11 项，新增双目标换边与预览关闭后的正常场景分配验证。埃德勒加入后，时间轴与 CFX 联合专项通过 22 项，包含 SHOT 的实际骨骼弹体、两侧轨迹和回放重建。

## 2026-11-14 交互修订

- 上部为角色/技能、预览、参数三栏，下部时间轴使用窗口全宽。分栏间有独立间距，可拖两条竖向分隔线调宽；拖预览下方分隔线可调时间轴高度。技能改为两行卡片，当前技能用蓝底与左侧标记显示。
- 播放/暂停、逐帧、循环、声音和速度均位于时间轴上方。预览上方保留目标与换边。
- **F / 聚焦选中**：将选中片段完整纳入视野，并滚到对应子轨；双击片段等效。**A / 显示全部**：恢复当前范围全貌。**C / 播放头**：将播放头移入视野。操作不改源节点时点。文本输入期间不抢这些快捷键。
- Shift+滚轮围绕鼠标所在时刻缩放；中键拖动或 Alt+滚轮横向平移。单击长片段中段只选中，不将视野强行拉回片段起点。帧标尺固定，不随轨道纵向滚走。
- 选中片段显示蓝色边框与深色底、白色文字；片段标签包含节点编号，时间轴与参数区同步显示选中摘要。模型时间轴事件标为只读。回退重建、逐帧、循环、重播、换边和对照原图后重新关联选中节点；不依赖上次播放器的对象引用。
- 节点身份按源 GUID 保留。无 GUID 的模型事件使用源内容与同内容出现序号重关联；普通回放不会混淆重复事件。若作者重排多个完全相同的父 ANI，模型只读事件的序号可能变化，需要重新选择；未来展开模型轨道编辑时需引入父 ANI GUID 与帧索引身份。

### 主演出与完整余辉

默认范围为主演出，包含角色动作、归位、镜头、HIT、显式 STG 完成等待、模型 Spine 特效和粒子发射阶段。开启 **含余辉** 查看完整粒子漂散范围；尾区标记为“附加特效余辉”。聚焦一个超出主演出范围的片段时自动展开完整范围。Cut-in 独立墙钟仍计入显示时长。

该范围切换只影响编辑器观察和循环终点，不修改源图、不裁去粒子，也不改变实战等待时序。亚敏 S3 的主演出约 6.067 秒，完整范围约 11.552 秒；雅卡泰丝 S2 实测 3.733 秒，含动作结束后的 0.2 秒源镜头收尾，未复现同样的长尾。

本轮还修正多组粒子颜色渐变被误拼接导致发射器创建失败的问题，覆盖亚敏和科尔布思 S3。源内每条渐变独立解析；每粒子出生时固定随机选择一条，重播使用同一随机种子。选择策略是当前项目解释，原引擎精确采样方式仍待实机对照。

具体回归、失败证据与未验证项见[编辑器交互修订验收](../delivery/2026-11-14-timeline-usability.md)。
