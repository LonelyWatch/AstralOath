## 音效对照

以原资源音频与录像音轨做波形相关匹配，`r` 为相关系数。00:01.962 的信封入口匹配 `ui/main_hud/btn_mail`（0.978），02:01.535 返回匹配通用返回音（0.883）。单项领取九次匹配 `ui/gain_rare`，批量确认匹配 `ui/msgbox/btn_yes`。01:07.860 的奖励阶段匹配 `ui/price_clear`，01:08.031 和 01:41.759 的「获得奖励」标题匹配 `uieff_msgbox_title.wav`。相同波形的资源别名只能确定声音一致。[测量结果](../../.artifacts/mail-reference/1122-audio/matches.json)
