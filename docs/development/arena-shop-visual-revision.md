## 来源和实现

原始布局 `D:/sevenepic/原始资源/wnd/shop_base_renew.csb`、`shop_exchange_base_renew.csb`、`shop_base_renew_bar.csb`、`shop_base_renew_tab.csb` 和 `shop_item_short.csb` 分别提供场景、列表及底栏、左栏、上栏、商品卡。`shop_base_renew_bar` 中的 `_tap_select_blue3` 带水平翻转。`shop_item_short` 为 232×282 设计单位，普通按钮引用 `_btn_green`，目录按钮引用 `_btn_blue`。商店分类图标按 `db/shop_category_new.db` 的 `icon` 和本地简中名称交叉核对，交易所采用 `icon_menu_normal`。源文件仅以只读方式访问。原版帧和修前实拍见 `.artifacts/arena-tower-review/frame-133.jpg`、`frame-136.jpg`、`final/shop-arena-reference-133.png`。

在 02:16 右侧没有商品遮挡的区域，将 `renew_shop_bg` 等比缩为 1417×600，并按像素平移与实帧计算去均值 RGB 相关系数。最佳匹配在裁去左侧 84 像素处（0.946），全屏居中裁切落在 92 像素（0.916）。原始场景背景的 X 为 -100 个 720 高度设计单位，映射到 600 高度后是 -83.3 像素。项目以该坐标左锚定，并在宽屏覆盖整个窗口。列表左缘另用原版 64×580 `renew_shop_bg_clipping` 补齐与列表相接的星光。

`Assets/Game/Editor/ArenaUiBuilder.ShopLayout.cs` 定义顶栏、八个分类、四个交易所页签、双行列表与底栏。顶栏复用现有返回按钮、货币项、邮件、频道聊天及快捷菜单控件。`Tools/Arena/ImportTowerShopArt.py` 导入本页所需原素材。`Assets/Game/Modules/Shop/Scripts/ShopWindowBinder.cs` 与 `StartupNavigation.TowerShop.cs` 将背包、快捷菜单和通用未完成提示接入相应控件。金币及天空石取当前玩家的服务器余额，征服点取商店回执。可用的未读数由各模块维护。录屏账号的活动、邮件及通知数字不会抄入运行状态。

右下赛季名对应本次收录目录。2026-3 这一档原片未带折扣，其他赛季原片所见徽章标明历史折扣，打开目录后明确显示其历史含义。项目的只读目录列六件已核实装备，说明行显示目录件数。按项目范围，目录不消耗征服点，不发放装备，不复制原录屏账号的限购和已购状态。玩家能在其他栏目上点击通用未完成提示。新消息、活动促销、充值加赠、其他商店的库存和额外音效都没有据此录屏伪造。

## 证据生成

`Assets/Game/Tests/PlayMode/ShopWindowPresentationTests.cs` 使用实际商店预制、模拟钱包及商品回执。传 `ASTRAL_ARENA_CAPTURE_SIZE=2464x1200` 或 `1920x1080` 和 `ASTRAL_SHOP_CAPTURE_DIR` 后，会分别写出 `shop-arena-reference-133`、`shop-arena-reference-136`、`shop-season-directory`、`shop-exchange-receipt` 的 PNG 和 `.bounds.json`。后者按相机最终坐标输出可见节点的真实位置。源码中的锚点和生成成功本身均不能证明画面通过。

使用 `python Tools/Arena/CheckShopLayout.py <截图目录>` 从实拍节点坐标检查侧栏八行、页签四列、首尾卡片大小与间距、页脚等位置。参考方的两张全尺寸图已从原录像直接无损截取至 `.artifacts/arena-visual-rework/shop-reference/shop-133.png` 和 `shop-136.png`，每张 2464×1200。

在命令末尾加 `--reference .artifacts/arena-visual-rework/shop-reference/shop-133.png`，会用 Pillow 和 NumPy 读取成图，对齐到 600 高度，由水平及垂直亮度变化求出第一张卡的实际边线，并按绿色通道筛出兑换按钮，逐边容差 3 像素。原片卡边左右为 256、413，上下为 128、321；绿色按钮左右为 268、401，上下为 284、313。第一轮宽屏的布局点已经符合目标，可见卡边却落在 261、409、134、317，按钮为 274、395、282、306。原素材带透明外缘，因此另以显示层校正可见边框，并调整按钮九宫切片密度、货币图标、标题与价格字号。商品排布和点击区域维持所测原位置。

第二轮 `round2/wide`（2464×1200）和 `round2/desktop`（1920×1080）的实际渲染读数相同。首卡边线为 257、413、128、322，按钮为 267、403、283、316。八个像素边界均在 3 像素容差内。页脚分隔线 y=538、尾列留白 150；顶部、分类、页签、两行商品间距和赛季文字均在上表范围内。人工已打开 02:13、02:16 对照及目录画面，见 `.artifacts/arena-visual-rework/round2/shop-visual-review.jpg`。两档编辑器 PlayMode 均为 5/5，其中本模块两条测试验证购买回执、余额、赛季只读、未开发入口以及网络异常后的同请求重试。编辑器实拍用于这组几何与可见像素读数，分发播放器证据由对应版本的总报告记录。此轮处理静态界面，未改变音频、粒子或动效。
