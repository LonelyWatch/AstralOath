# AI 任务与交接模板

复制到当前任务记录，按实际证据填写。完成项只记录实际观察，不能把计划、文件存在或编译通过写成运行验收。

## 目标和验收

- 用户目标、已确定的选型、目标分支及明确不在本次范围的功能。
- 可观察的验收行为：输入、动作、预期显示/事件/持久化结果和取消/失败路径。
- 当前版本、配置 schema、协议及资源版本；是否需要维护更新。
- 涉及玩家可见表现时，按入口、区域、交互状态逐项写出已查看的效果图或录像时间点，并标出仍需向用户索取的画面。

## 修改边界

- 文件所有权：每个 Agent 的独占目录，唯一 Unity 操作者与 Git 提交者。
- 相关模块的公开接口、依赖方向、生命周期和释放责任。
- 唯一配表编辑源、生成命令、生成快照路径、资源来源/哈希与依赖闭包。
- 新决策写入 ADR；涉及用户已决定的基础设施变更先明确提出。

## 验证记录

- 回归触发与修复前失败证据；具体命令、运行环境、退出码及结果路径。
- .NET、真实 MySQL、Unity EditMode/PlayMode、目标构建、实际 Player/设备分别记录。
- 检查取消、重复调用、超时、销毁/复用、订阅和资源释放；更新检查签名、文件、空间和回滚。
- 独立审查发现、处理结论、针对修复的复验，未验证项及原因。

## 原版、修改前与修改后对照

每个入口/状态或行为用例单列一项，按[通用验收](project-standards.md#任务完成后的通用验收)先自行核对，再整理交付；以下字段不能只填「见测试通过」。

### 验收项：填写编号、入口/区域/状态或行为

- 原版实际效果／目标依据：来源可打开位置、版本/角色形态/语言、录像时间段及已知倍速；实际观察或已确认需求/契约。
- 修改前效果：基线提交、同状态原始截图/录像/音轨或行为/数据/原文，文件位置及具体差异。未留证据、新功能此前不存在等情况如实标明，不能事后伪造。
- 修改后效果：最终提交、配置/资源版本和实测包标识；同状态实拍/音轨或行为/数据/diff 的可打开位置。
- 自行比对：实际已观看/试听/执行的项目，原版与修改前后哪些一致、哪些仍有差异，比较条件及不同账号/数值/版本的影响。
- 验证结论：实际通过／失败／环境阻塞／未执行；命令、平台、环境、退出码、日志路径和复验结果。视听不适用项及具体理由。

### 音效、动画与特效（涉及时填写）

- 原版／修改前／修改后各自的可听音频或可播放片段、时间段和原始文件位置；与上述验收项编号对应。
- 触发操作、事件/素材标识、比较音量及播放倍速、持续时长，起止、取消/淡出、重叠播放、动作与光效对位等实测。
- 实际试听/观看结论及差异；尚未播放就写未验收，波形/绑定/静态截图不替代实际听感和连续时序。非视听任务说明不适用理由。

## 文件变更与位置清单

- 按新增／修改／重命名／删除列出文件、用途及可打开的绝对路径；代码/文本按需给行号，预制和资源给层级/BindingMap key、GUID或资源地址。
- 配表、协议或生成预制同时列权威编辑入口、生成命令及产物位置；来源清单和证据目录也给准确位置。
- 清单覆盖本次实际变更，不把源目录、缓存或上一任务文件混为本次修改；完整清单较长时提供可打开索引并在交付中列关键文件。

## 未完成与未验证内容

- 每项写具体内容、未完成/未验证原因、用户可见或数据/构建影响、尚需的资料/环境及下一步最小操作。
- 区分参考缺失、规则待核、尚未实现、环境阻塞、明确不在本次范围；避免只写「后续优化」。不影响其他工作时继续完成已获授权的独立部分。

## 交接与发布

- 源码提交哈希、远端分支、启动/复现命令、日志与产物位置。
- 图录、音视频及报告对应的提交、平台、母包/内容版本；列源码提交、Editor 验证、构建、实际安装验收、分发各自状态。未打包/未分发明确填写，旧图不能代替最终包验收。
- 本机启动的测试进程及清理责任；不把临时凭据或私钥写入交接。
- 仍需用户监督的具体行为与输入素材、缺失内容、下一步最小验收。
- 国际服追踪只响应用户的明确指令；普通开发 CI 不进行外服采集或生产部署。


## 文档同步（提交前填写）

- 变更日志条目及对应模块README更新位置。
- 接口/配置/资源/操作方式变化；对应规范或操作说明的位置。
- 当前状态是否改变；project-status更新或无需更新的具体理由。
- ADR是否需要；用户既有选型是否保留。
- `node Tools/check-docs.mjs --staged`结果；推送后CI运行链接和结果。

## 中断时的最小交接

- 主工作区、分支、基线、已提交/未提交文件、Agent所有权。
- 最后成功的命令和证据；正在运行的进程/测试及清理责任。
- 当前失败原因、下一条可执行命令、尚缺的信息/外部环境。
